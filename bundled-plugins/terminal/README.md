# Terminal · Aide 设备终端工作台

**1.4.0 预发布，市场已收录，需配套宿主能力。** 统一 Shell、SSH、TCP、UDP 与串口调试工作台，提供常驻会话和日志，交互参考 [WindTerm](https://github.com/kingToolbox/WindTerm) 的会话列表、标签和日志组织；没有复用 WindTerm 源码。

## 安装预发布版

从 [v1.4.0 预发布](https://github.com/skyelan1999/aide-pkg-terminal/releases/tag/v1.4.0) 说明中的固定提交链接下载 ZIP 和 SHA256SUMS，经 `sha256sum -c SHA256SUMS` 校验后导入。安装包托管在仓库 `packages/v1.4.0/`，Release 提供下载链接，没有另行上传二进制附件。请先采用配套宿主源码构建；当前公开旧宿主不能完整使用此工作台。

插件新标签页入口已移除；后台会话、日志及 Aide 管理能力继续保留。宿主界面变更需要更新 Aide main 源码构建，单独升级插件不会替换宿主界面。

## 使用

在配套 Aide 中启用 Terminal，点击“打开工作台”，选择“新建会话”。“工作区 Shell”在本地工作区使用 Aide 本地 PTY；在 SSH 工作区则复用 Aide 已认证的工作区 SSH 连接，并进入远程工作区目录。新建的“远程 SSH · 设备连接”由 **Aide 运行环境**的 OpenSSH 客户端连接目标设备。可以同时调试不同设备，切换标签或关闭工作台不会结束后台会话。点击“结束”并确认才结束连接，保留原有日志；已结束的会话可以明确删除记录和日志。

SSH 首次连接在终端显示主机指纹，请通过可信途径核对后输入 `yes`。指纹变化由 OpenSSH 拒绝连接；本插件不会自动忽略校验。认证方式可选默认身份、用户名和密码、私钥文件。密码和加密私钥口令在终端提示后输入；记录只保存用户名、地址、端口、认证方式与私钥文件位置，不保存密码和口令。私钥可手动填写当前来源内的相对路径，或点击“从工作区 / 引用选择…”浏览当前工作区以及已启用、允许访问的本地、Skill、SFTP、工作区 SFTP 引用来源。私钥内容由宿主限量读取，经 daemon 私有通道交给 Linux 内存文件，不传给网页、不加入工具参数或连接记录，也不新增私钥磁盘副本。原始私钥文件仍由用户管理。没有启用 agent 转发、端口转发，也不会读取用户 SSH config 的 ProxyCommand。

工作台按本地、SSH、历史会话分组，支持名称/主机搜索与运行状态筛选；标签栏只显示活动会话和当前选中的历史会话。桌面右侧显示真实连接状态、目标、起始目录、创建时间和日志详情。工作台在当前 Aide 页面内打开，窄屏使用会话抽屉。提供 xterm 终端、窗口尺寸适配、Ctrl+C、输出查找、日志开关与下载。命令和按键直接发送到目标会话，请确认当前标签对应的设备。关闭面板不会自动发送尚未送达的输入，也不会重试结果不确定的写操作。

SSH 工作区 Shell 沿用工作区设置中的密码、私钥或引用私钥认证，不在终端面板再次保存一份凭据。连接固定到已认证主连接；切换工作区、主连接断开后不会自动改接其他主机。远程主机需具备 `/bin/bash`，所填起始目录用于工作区 Shell；设备 SSH 登录后的目录由远端账户决定。

## TCP、UDP 和串口工作台

“新建会话”可选择 TCP 客户端、TCP 本地监听、UDP 数据报或串口。TCP 监听仅绑定 Aide 运行环境的 `127.0.0.1`，端口0自动分配；新客户端接入后显示独立会话，选择客户端会话进行发送。UDP 可指定目标主机/端口和本地接收端口，发送复用同一个已绑定 socket，设备可向该端口回复。串口提供设备路径、波特率、数据位、停止位、校验与 RTS/CTS 流控，并可刷新可用设备列表。

通信会话使用独立报文发送栏：选择 UTF-8 或 HEX，文本可附加 LF/CRLF/CR。仅点击“发送”才写出报文，不按键逐字发包，不自动重发结果不确定的写入。HEX 必须为完整字节。接收视图和轮转日志保留时间、TX/RX、端点、长度、完整十六进制与可读文本，因此二进制数据和 UDP 报文边界可追溯。日志关闭后不再落盘，仍保留有界内存回放。

所有设备通信均从 **Aide 运行环境**发起；SSH 工作区只改变工作区 Shell 与会话归属，不把 TCP/UDP/串口执行位置自动迁移到远程主机。容器访问物理串口需要预先映射对应设备并具备权限。Linux 原生串口绑定与虚拟 PTY 回环已验证；真实 USB/UART 硬件、Windows/macOS 未实测。

## 合并的高级通信工具

原 comm-ssh、comm-tcp、comm-udp、comm-serial 的35个工具合并到 Terminal，统一加 `terminal_` 前缀；原插件保持可用，工具名不会相互覆盖。Aide 可直接调用这些工具，工作台内部通过受限 `terminal_session_comm` 分发。工具连接、发送、文件传输、代理、回放和模拟均需用户明确意图。

| 前缀 | 功能 |
| --- | --- |
| `terminal_ssh_*` | 密码/公钥连接、exec、SFTP 列目录/下载/上传、本地隧道、模拟 SSH/SFTP 服务端及规则 |
| `terminal_tcp_*` | 连接/监听/发送/关闭、代理、模拟应答、录制回放与有界边界报文探测 |
| `terminal_udp_*` | 绑定/发送/关闭、模拟应答、回环组播加入/离开 |
| `terminal_serial_*` | 列出/打开/配置/写入/关闭串口、虚拟串口对、按帧回放 |

`terminal_ssh_fingerprint` 额外提供只读指纹探测，返回 `verified:false`。高级 SSH API 连接必须提供经用户可信途径核验的 `hostFingerprint`（`SHA256:...`）；获取指纹本身不等于信任。工作台 SSH 保留 OpenSSH 的指纹确认与严格 known_hosts 行为。高级 API 的 password/privateKey/passphrase 沿用原插件的临时调用参数，插件不持久化；文件引用模式由宿主通过私有上下文传递私钥，工作台密码与口令仍在终端交互输入。

通信资源按工作区独立管理，API 连接/隧道/模拟服务等句柄包含作用域身份，不能跨工作区使用；后台重启后旧句柄失效。基础 TCP/UDP/串口工具创建的连接也会显示在工作台。高级 SSH API 连接用于 exec/SFTP/隧道，与工作台交互式 SSH PTY 是各自的连接。SFTP 本地文件必须位于当前**本地工作区**，拒绝越界与符号链接逃逸；SSH 工作区不以本地安装目录作为文件传输回退路径。

每个工作区最多32个通信资源，模拟规则/显式回放最多64条、总输入256KiB；TCP 保留最多32份录制，每份最多2MiB/2048帧。原有会话32条记录/16条活动限制继续生效。TCP监听、代理、SSH隧道和模拟服务只在回环监听；UDP组播沿用原实现的显式组播模式，绑定全地址但组成员接口限定回环。管理员禁用的通信工具不能经通用入口或会话发送绕过。

## 后台生命周期与数据

“驻留”指 **Aide 与插件后台持续运行期间**，浏览器关闭、刷新或切换面板后会话继续运行。停用/重启插件、升级插件或停止 Aide 会结束连接。重新启动后台会恢复会话记录及日志，将未正常结束的记录标记为“后台已重启”，不会自动重连或重放设备命令。断线不会自动重新认证；请新建会话。

本地工作区数据保存在 `.aide/terminal-workbench/`。SSH 工作区数据保存在 **Aide 数据目录**的 `terminal-workspaces/<工作区标识>/.aide/terminal-workbench/`，按远程目录、主机、端口和用户隔离，不会回退到本地安装目录，也不会向远程设备写入会话日志。替换插件文件不会覆盖日志。目录权限 `0700`，文件权限 `0600`。请把这个目录加入项目的 Git 忽略规则；备份或清理工作区时按需保留它。

- 每个会话最多保留 **4 × 2 MiB** 原始输出日志，达到上限自动覆盖最旧分卷；每个工作区最多32条会话记录，整个插件后台最多16个运行会话。删除已结束记录可以释放名额和对应日志。
- 日志只捕获 PTY **输出**，不单独存储键盘输入；OpenSSH 的密码提示关闭回显。设备或应用自行回显的命令、口令及其他敏感内容仍会被记录，必要时先暂停日志。
- 日志保留 ANSI 控制序列，文件名是会话 ID，开始/结束时间在同名 JSON 元数据中。无需打开工作台，后台仍会记录输出。磁盘写入失败时工作台显示错误，已有内存输出仍可查看；检查存储后重新开启日志即可重试后续写入。
- 输出回放保留最近512 KiB，超出会明确提示恢复的是尾部；磁盘日志独立保留。查看日志可选择单个分卷准备下载，然后点击 **Aide 顶部“保存文件”**。下载固定文件身份和起始大小；读取期间发生轮转则报错，不会混合不同文件。

## 运行要求与兼容性

Node.js 24、Linux Python 3 标准库 PTY（引用私钥使用 memfd）、`/bin/bash` 和 OpenSSH 客户端。安装包内置固定版本 ssh2 1.17.0、serialport 12.0.0 及其运行依赖与许可证，目标环境无需执行 npm install；终端 JS/CSS 内嵌、无需 CDN。当前在 **Linux 原生运行环境**实际验证；Windows 用户可通过 Aide Linux 容器使用，终端执行的是容器 Shell。Windows 原生 PTY 未实现，macOS 未实测；这不代表 Windows PowerShell、宿主机终端或设备串口支持。

市场安装另外要求配套宿主识别 `terminal-workbench-v1`。1.4.0 需要 Aide 同时支持 `terminal-communications-v1`、`terminal-ssh-workspace-v1`、工作台 `bridge.renew` 和 `daemon.detach` 能力（配套 [Aide 宿主变更](https://github.com/skyelan1999/aide/tree/main)）。旧宿主可以识别工作台声明，但此版本会禁用会话创建并提示升级，避免旧桥接128次调用上限或取消请求导致后台停止。**不能只把新插件装入旧版 Aide 后宣称完整支持。**

插件是可信 Node 代码，不是权限沙箱；交互 Shell 和 SSH 具有 Aide 运行用户的系统权限。工作区边界用于起始目录、私钥路径和会话归属，不限制 Shell 后续能访问的路径。`read-only` 宿主策略会拒绝调用这些插件工具。锁屏、工作区切换、插件停用仍按宿主策略撤销当前面板权限；取消正在执行的工具时宿主可能结束对应后台实例，以防未确认的后续副作用。


## 1.4.0 串口连接与选择修复

串口会话提供明确的设备下拉选择，展示路径、厂商和序列号，支持刷新与手动输入。进入串口类型时自动枚举；不会自动连接任何设备。Linux 缺少 udevadm 或 udev 未登记容器设备时，补充扫描可见的串口字符设备和 by-id 别名。打开失败后释放连接状态，可直接修正参数或权限后重试；权限拒绝和占用错误提供具体提示。

Windows 通信会话不再被仅适用于 Shell 的 PTY 限制阻止，串口路径接受 COM3 等名称；Windows 真实串口仍未实测。Docker 内不能凭插件自动访问宿主 COM 口：必须由运行环境映射或转发设备，并配置访问权限。SSH 工作区不会自动将本机串口改为远程 SSH 设备的串口。

验证包含 Linux 原生虚拟串口二进制回环、失败重试、无 udev 枚举与设备选择 UI；物理 USB/UART、Windows/macOS 和用户具体设备环境仍待实测。

## 加密中继部署与 Aide 可见性（1.4.0）

新建 SSH、TCP、UDP 或串口会话时，勾选“通过中继部署”，填写设备侧目标信息、中继地址及固定 TCP 端口（默认 17780）。加密密钥可留空自动生成，或填写 32 字节随机密钥的 Base64 文本。会话先保存为“等待中继部署”，不会立即连接目标。

1. 选中会话，点击“下载部署脚本 .py”，再在工作台标题栏点击出现的“保存”按钮完成下载。脚本已包含目标主机/端口或串口参数、监听端口和密钥，无需手工编辑。
2. 将脚本放到可访问目标设备的电脑上。准备 Python 3.10+ 并运行：

```sh
python3 -m pip install cryptography
# 串口目标另外需要：
python3 -m pip install pyserial==3.5
python3 aide-relay-<会话ID>.py
```

3. 确保 Aide 可以访问中继 TCP 端口，点击“检测在线”。在线只代表中继认证成功，不代表目标设备已连接；检测不会打开串口或目标连接。
4. 点击“连接中继”。SSH 保留主机指纹核验与密码/引用私钥流程；串口使用中继电脑上的设备路径，例如 Windows COM3。UDP 保留报文边界，经 TCP/TLS 帧传输。会话仍显示 SSH、TCP、UDP 或串口，额外标记“中继模式”。

数据链路采用 TLS 1.3；本端在发送应用数据前核对由密钥派生的中继公钥，并使用随机挑战/HMAC 认证客户端。没有自制流加密算法。脚本包含密钥，需像设备凭据一样妥善保管；中继只连接脚本中固定的目标，不接受客户端任意指定地址。每个脚本固定一个目标，最多8个认证连接；串口同时只允许一个连接。脚本不自动注册系统服务，按用户命令前台运行。

Shell/SSH 命令、设备收发与日志仍沿用原会话机制；中继在线状态每15秒检测一次，也可手动检测。中继断开后不会自动重连或重发。该版本不支持通过中继创建本地 Shell 或 TCP 监听会话，使用 SSH 会话连接远程 Shell。

创建时及连接工具栏均可设置“对 Aide 可见”（默认开启）。关闭后，Aide 会话工具无法列出、读取输出/日志、发送或关闭该会话；工作台用户仍可管理。只有宿主认证的工作台调用能修改可见性或导出部署脚本，模型参数不能伪造此身份。存在隐藏会话时，底层批量通信接口对 Aide 收紧，可见会话仍可通过其专用工具操作。此开关控制插件接口，不替代宿主系统权限或可信插件的信任边界。

配套宿主将终端状态、日志和中继密钥放在 Aide 私有服务数据目录，按工作区隔离。升级时旧状态会迁入，原文件逐字节确认迁移后移除；不要在迁移期间运行两个实例操作同一工作区。密钥文件使用当前运行用户的私有文件权限，不作为普通会话字段返回，不写入流量日志；这不等同于额外的静态加密。新版本需要宿主支持 `terminal-relay-v1` 和新的私有调用上下文，不能仅升级插件替代宿主更新。

实际测试包含生成脚本的 TCP/UDP/TLS 收发、错误密钥/认证拒绝、Python pyserial 虚拟串口透传、OpenSSH 经中继认证、隐藏状态持久化和真实浏览器下载/部署/连接。物理 USB/UART、Windows/macOS 设备侧部署及完整 start.command 宿主 UI 尚未实测。

降级前应备份 Aide 私有会话状态；旧版本不读取新私有目录，不会自动反向迁移。已有设备会话在插件升级时断开，不自动重新连接。
