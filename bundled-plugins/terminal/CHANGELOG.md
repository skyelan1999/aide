# Changelog

## 1.4.0（预发布）

- 可选设备侧 Python 中继，下载已配置目标的脚本，通过固定 TCP 接口和256位密钥认证的 TLS1.3 传输。
- SSH/TCP/UDP/串口保留原类型，新增等待部署、在线探测、连接与中继标识。
- 新增会话对 Aide 可见开关，可信工作台身份在宿主绑定；隐藏会话拒绝列出、读取、发送及管理。
- 状态、日志和密钥迁入服务私有目录，旧状态验证迁移，保留既有会话和日志。
- 需要支持 terminal-relay-v1 的配套 Aide 主机。

## 1.3.2（预发布）

- 串口下拉选择、自动枚举与刷新，保留手动路径。
- Linux 无 udev 或容器设备未登记时扫描可见串口设备。
- 修复打开失败后残留已打开状态，补充权限与占用提示。
- 修复 COM 路径校验及 Windows 通信会话误受 PTY 限制。

## 1.3.1（预发布）

- 修正串口 RTS/CTS 流控选项到原生驱动 rtscts 字段的映射，并通过原生虚拟串口配置及收发验证。
- 保留1.3.0合并的35项通信功能及不可变归档。

## 1.3.0（预发布）

- 合并 comm-ssh、comm-tcp、comm-udp、comm-serial 的35个可执行工具，使用 terminal_ 前缀避免冲突。
- 工作台新增 TCP 客户端/本地监听、UDP 与串口会话，支持显式 UTF-8/HEX 报文发送及文本行尾。
- 通信日志统一记录 TX/RX、端点、完整字节与可读文本；沿用轮转存储和后台生命周期。
- 增加主机指纹核验、作用域句柄、SFTP本地路径限制、禁用策略与有界录制。
- 安装包内置固定版 ssh2、serialport 和运行依赖；需要配套 Aide main，仍为预发布。

## 1.2.0（预发布）

- 工作区 Shell 支持本地与 SSH 工作区，SSH 模式复用已认证主连接并进入远程目录。
- 设备 SSH 明确区分默认身份、用户名密码与私钥认证，加密私钥支持终端输入口令。
- 增加工作区 / 引用来源私钥文件选择器，私钥经宿主私有通道和 Linux memfd 使用，不进入网页或会话元数据。
- SSH 工作区日志在 Aide 数据目录按主机、端口、用户与目录隔离；固定主连接 inode，避免工作区切换误连。
- 需要配套 Aide main 的 terminal-ssh-workspace-v1 能力，仍为预发布；不再提供插件新标签页入口。

## 1.1.2（预发布）

- 配套 Aide main 移除插件新标签页按钮、链接自动打开和专用布局，仅保留当前页面工作台。
- 保留后台本地/SSH 会话、日志及 Aide 会话管理；单独升级插件不会替换宿主界面。
- 仍要求 terminal-workbench-v1、bridge.renew 与 daemon.detach 宿主能力。

## 1.1.1（预发布）

- 重排设备终端为连接导航、主终端与桌面连接详情三栏，优化专业/经典明暗主题和手机布局。
- 会话按本地、SSH和历史分组，新增搜索与运行状态筛选，历史记录不再挤占活动标签栏。
- 桌面详情显示实际状态、连接目标、目录、创建时间与日志信息；保留后台驻留与Aide会话管理工具。
- 配套宿主将独立标签页铺满窗口并压缩外层标题栏；仍要求PR #7中的宿主能力，不替换稳定市场。

## 1.1.0（预发布）

- 增加常驻设备终端工作台：本地 PTY、OpenSSH、多会话标签与列表、输出查找及尺寸适配。
- 关闭或刷新工作台后保留运行会话；后台重启仅恢复记录和日志，不自动重连或重放命令。
- 输出日志按工作区和会话落盘、轮转、暂停、分页下载及明确删除；不另存键盘输入或 SSH 密码。
- 使用离线内嵌 xterm.js；要求宿主支持受控桥接续期和 daemon detach，旧宿主明确提示升级。
- 配套宿主增加“新标签页打开”，关闭原页面后可独立调试。
- 保留原 `terminal-run` 提案及 `terminal-history` 目录工具。

## 1.0.0

- 将 Aide 已有 Terminal 插件独立分发，保留 MIT 许可。
- 保留原代码、manifest、版本和安装包字节内容。
- 补充实际能力说明：`terminal-run` 只生成命令提案，`terminal-history` 只读列举目录；没有交互式终端或命令历史存储。
