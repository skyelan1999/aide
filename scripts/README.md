# `scripts` 维护工具

按“是否是稳定入口”区分根目录命令与专项工具：`aide.sh`、`agent-route.py`、发行和安装脚本由启动器、CI 或开发流程直接调用，留在根目录；可归属到单一用途的程序放入子目录。

- `office/`：Office 文件读取与写入辅助工具。
- `fixtures/`：仅用于开发和验证的固定样本、模拟服务；`mocks/` 放外部服务替身，不承载生产服务。
- `git-hooks/`：仓库 hook。

迁移被调用的脚本时，必须同步更新 Docker `COPY`、文档命令和开发路由引用。测试文件留在项目级 `scripts/` 入口，是因为现有脚本按仓库根目录解析资源；若重定位，需先统一根目录解析方式并保留原命令兼容。
