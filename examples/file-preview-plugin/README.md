# OBJ文件插件示例

演示按扩展名接管预览、旋转线框和编辑OBJ源码，需要本次新增的Aide文件桥。它不是完整CAD，也不会默认安装。

```sh
python3 examples/file-preview-plugin/build.py
```

在插件管理导入生成的 `example-plugin.zip`，启用后将 `cube.obj` 放入工作区或本地/SFTP引用，从文件列表打开。停用插件或选择「工作台原生预览」恢复原有文本界面；只读引用不能保存。

点击「准备保存修改」仅暂存，还需点击宿主「保存到原文件」。等待保存期间锁定该份编辑文本，收到document.saved后才能更新版本和“已保存”状态。示例按8MiB/10万顶点限制演示模型，这不是宿主文件桥的总大小限制；完整建模插件应自行实现流式解析和输出。

`viewer.src.html` 是源文件，`viewer.html` 为构建生成的自包含页面。构建内嵌仓库中的新版客户端，所有输入/保存请求串行，无外部资源、无原生文件读写工具。ZIP仅供手动安装示例，不是市场包，按仓库MIT许可分发。
