## 1. 我们收集什么、存在哪

aide 默认是一个**在你自己机器上运行的工具**。它不会把你的对话、记忆或凭据上传到我们或任何第三方服务器——除非你**主动**配置了下列可选服务。

| 数据类型 | 存放在哪 | 是否加密 | 保留多久 |
| --- | --- | --- | --- |
| 对话历史（sessions/） | 本机 Docker 卷 `/data/sessions/` | 由账户密码派生密钥保护的小秘历史信封；普通会话文件在 0700 卷内 | 直到你删除会话或执行出厂重置 |
| 小秘对话历史（assistant/voice-history.json） | 本机卷 | AES-256-GCM 加密信封 | 直到你清除或重置 |
| 小秘长期记忆（assistant/voice-memory.json） | 本机卷 | 当前为明文，受 0700 卷保护 | 直到你清除或重置 |
| aide 核心记忆（memory/core/） | 本机卷 | 明文，受 0700 卷保护 | 直到你清除或重置 |
| 你的密码 | 本机 auth/password.phc | Argon2id 哈希（不可逆，非明文） | 直到你改密或重置 |
| 访问令牌 / KDF 盐 | 本机 auth/，0600 | 令牌为随机数；盐用于派生密钥 | 直到重置 |
| AI API Key | 本机 config/settings.json（当前明文，受文件 0600 + 目录 0700 保护） | 应用层明文（见残余风险） | 直到你删除或重置 |
| 第三方密钥（SSH 等） | 本机 secrets/vault.enc | AES-256-GCM 加密信封 | 直到你删除 |
| 审计日志（audit/） | 本机卷，0600 | 仅记动作元数据，不记对话正文 | 本机滚动保留 |
| 调试令牌 | 本机 settings.json | 仅存 SHA-256 哈希 | 直到你吊销或关闭诊断 |

## 2. 数据何时离开你的设备

只有在你**显式配置**以下任一项时，相关内容才会发往你指定的端点：

1. **外部 AI 模型 API**：你在设置里填写的 BaseURL 与 API Key。你的提示词、附件内容会发往该端点以获得模型回复。
2. **edge-tts（微软 Edge 在线朗读）**：当你选用 edge 语音引擎时，待朗读文本会发往微软的朗读端点。
3. **自建音色克隆服务**：当你配置了克隆服务 BaseURL 与 API Key 并选择克隆音色时，待合成音频会发往该服务。

上述第三方服务的隐私实践不在 aide 控制范围内；请阅读你所选服务各自的隐私政策。

## 3. 我们不做什么

- 不内置广告、不做用户画像广告定向。
- 不发送遥测、崩溃上报或使用统计到我们的服务器。
- 不使用追踪 Cookie；Web 界面用一次性 Bearer 令牌鉴权。
- 不把你的密钥、密码哈希、对话正文写进审计日志。

## 4. 你的权利与控制

作为本地自托管者，你对数据拥有完整控制权：

- **访问/导出**：设置中可导出配置备份（默认脱敏，不含密钥/密文；勾选才随附）。
- **更正**：直接在界面编辑设置、删除或重开会话。
- **删除**：删除单个会话、清除记忆，或执行**出厂重置**清空全部个人数据。
- **可携带**：导出的 JSON 备份可在另一台机器导入（加密信封在跨机时不可解，需重新录入密钥，属预期）。
- **退出同意**：取消外部 Provider 配置即停止外发；关闭诊断接口即吊销调试令牌。

## 5. 安全措施摘要

传输全程 TLS1.2+（仅回环绑定）；密码用 Argon2id 慢哈希；凭据用 AES-256-GCM 加密信封；敏感文件 0600、目录 0700；审计日志只记动作不记正文。详见 [security-audit.md](./security-audit.md) 与 [eu-compliance.md](./eu-compliance.md)。
