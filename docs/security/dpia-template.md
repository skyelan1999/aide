## 3. 风险识别

| 风险场景 | 可能性 | 影响 | 现有缓解 | 残余等级 |

| 账号弱密码 | 中 | 派生密钥被暴力破解 | Argon2id 64MiB/t=3/p=4 | 低-中 |

## 4. 缓解措施（对应 GDPR Art.32）

1. 传输：TLS≥1.2，ECDHE+AES-GCM，回环绑定。
2. 静态：SSH 凭据 AES-256-GCM vault；小秘历史加密信封；密码 Argon2id。
3. 最小权限：敏感文件 0600、目录 0700；vault List 不回密文。
4. 默认隐私：诊断接口默认关、插件默认禁、无 Cookie。
5. 可追溯：审计日志记动作不记正文。
6. 用户可控：导出/删除/出厂重置。
