# 局域网访问授权

设置入口：**数据与账户 → 账户 → 局域网访问授权**。此功能默认关闭；需要已设置账户密码。开启时验证账户密码并立即保存，锁屏时间原为 0 时自动设为 300 秒；开启期间，普通设置 API 拒绝把锁屏时间改为 0。关闭不要求再次输密码。

## 手机和其他设备

1. 通过新版启动器构建/启动 Aide；主机与访问设备连接同一局域网。
2. 在本机设置中开启授权，等待 HTTPS 地址和二维码出现。二维码只包含 `/lan-login.html` 地址，不包含密码、令牌或免密票据。
3. 手机扫码，或其他设备浏览器输入显示的 HTTPS 地址。首次访问需要在该设备上信任本机自签证书，并核对设置中显示的 SHA-256 指纹；不会自动修改设备证书信任或防火墙。
4. 输入 Aide 账户密码登录。密码不会进入地址或二维码；成功后给该设备签发独立随机会话令牌，主 access-token 不返回设备。

当前只支持宿主物理接口上的私有 IPv4 地址，不创建公网隧道、不修改路由器或防火墙。地址准备失败时设置显示局域网桥未就绪，不能把尚未出现地址当成连接成功。端口由宿主桥分配，重启或网络变化后应使用新地址。

## 传输与授权边界

主工作台端口保持 `127.0.0.1` 发布。容器另设固定端口 `45842`，同样只发布到宿主回环；宿主 `aide-message-lan` 接收固定目的地 `-remote-target`，只按有效的 45 秒租约打开私有局域网监听。后端每 10 秒续约，正常关闭授权时主动释放。helper 只转发 TLS 字节，不持有密码、私钥或会话明文。请求不能指定任意转发目标。

独立入口仅处理真实 TLS 请求，忽略伪造的转发协议头；Host 必须与租约地址一致，API 还要求同源。无论 Host 如何填写，本机主令牌都不能在此入口代替密码会话。外部设备不能调用本机授权开关或独立诊断接口。已登录设备获得正常工作台权限，因此只向信任的设备授权。

LAN 叶证书存为 `certs/lan-cert.pem` / `lan-key.pem`，ECDSA P-256，私钥 `0600`，30 天有效；SAN 仅包含当前私有地址。地址不变且证书有效时复用，地址变化或接近到期时更新。既有 localhost 证书不轮换。TLS 复用已有 TLS 1.2+/ECDHE/AEAD 配置。首设备证书信任属于设备持有人的操作；加密传输不等于已由公共 CA 认证。

## 会话与锁屏

会话只驻留服务器内存；服务重启后重新输密码登录。令牌为 256 位随机数，只保存其哈希作为服务端索引，最多 32 个并发会话，最长 8 小时。空闲时长服从锁屏秒数，只由设备真实键鼠/触摸活动续期；自动轮询、SSE 和保活检查不续期。

关闭授权、修改密码、锁屏、空闲或绝对期限到期，会拒绝旧令牌并取消活动请求上下文。客户端定期检查授权，失效时退出当前工作台。设备退出入口仅撤销当前令牌。账号密码验证复用现有有界 JSON 请求解析、Argon2id 验证和共用失败冷却预算。局域网登录及锁屏恢复均使用密码，本机 Touch ID / Windows Hello 的原有登录路径保留。

导入备份不会激活授权；清除账户凭据会关闭授权。持久化只保存授权开关与原有锁屏参数，不保存设备会话。

## 验证与限制

回归和页面观察见 [局域网验收](../reviews/2026-11-03/lan-access/README.md)。隔离 TLS 浏览器测试、转发测试和编译不能代替用户真实手机证书信任、物理网络、防火墙或 Windows 实机启动验收。本次不启用用户运行实例，不创建 Release。

二维码使用固定版本的 [go-qrcode](https://github.com/skip2/go-qrcode)，本地编码；源码与 MIT 许可随 vendor 保存，模块摘要由 `go.sum` 校验。运行时不访问二维码服务。
