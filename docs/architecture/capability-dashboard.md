# 连接与插件能力仪表（源码候选）

设置 → 连接与能力。页面将启用配置、最近的插件宿主登记、守护进程状态及具体检查结果分开显示。打开页面和“重读能力状态”仅读取状态；每30秒在当前可见设置页重读，不自动连接远端、导入依赖或调用模型。点击“检查此项”才执行对应步骤。

## 检查范围

| 项目 | 实际检查 | 不证明的能力 |
| --- | --- | --- |
| 本地工作区 | 固定根目录打开并读取一个目录项 | 文件写入、删除、所有子目录权限 |
| SSH工作区 | 已保存配置的认证连接与根目录列表 | 远端写入、shell执行、每个子目录权限 |
| 普通引用来源 | 沿用来源列表实现读取根目录 | 可写权限；来源根目录列表不一定是全部内容 |
| MCP来源 | 启动已配置进程，initialize与tools/list | 不调用工具；进程初始化本身可能有副作用 |
| 插件 | 受限根目录中的普通入口文件读取和摘要 | 不执行插件或工具；宿主工具数为最近登记元数据 |
| 文档依赖 | python3 -I -B导入pypdf/docx/openpyxl/pptx | 不处理实际文档，不证明渲染、加密PDF或OCR能力 |
| 模型 | GET已保存API地址的/models，不跟随重定向 | 不调用生成，不证明视觉、推理、工具调用；有些提供商不支持此接口 |

MCP检查有明确进程启动提示，由用户选择继续。其余步骤沿用已保存连接和凭据，检查不修改配置或增加授权。普通文件检查不写探针文件；因此“配置允许写入”始终与“写权限已验证”分开。失败说明按步骤生成，不回显上游正文、stderr或凭据。

## 时效与并发

结果包含时间、耗时及范围，仅保存在当前服务进程的有界缓存；五分钟后标为失效，重启清空。工作区代际、配置和凭据发生变化后旧观察失效，检查期间变化返回409且不采纳结果。一次只运行一项检查；另一请求返回409。并不持续监测外部文件、外部服务器或插件源码变化，五分钟内的历史通过也不保证此刻仍可用。

设置切换、关闭、锁定和页面离开后不再更新旧面板；已开始的服务端检查可能继续至现有连接超时，不自动重试写操作。界面轮询仅读取元数据，不发起检查。

## 接口

- GET `/api/capabilities`：当前workspaceId、各项公开配置指纹与观察结果、是否正在检查。
- POST `/api/capabilities/check`：key、fingerprint、workspaceId；4096字节限额。配置/作用域变化或检查忙时409；不存在404、未启用400。
- 检查执行失败仍以200返回 state=failed，是检查收据而不是操作成功；内部比较绑定与凭据不返回给浏览器。

接口沿用全局鉴权及锁态，不是权限授予接口，不改变来源对AI的可见性。读取检查结果不代表该来源适合进入模型上下文。
