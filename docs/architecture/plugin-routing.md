# 商店插件路由与按需安装

商店维护能力索引，Aide 宿主负责匹配、工具加载和安装权限。无需安装额外路由插件，也不将独立插件重新捆绑进宿主。

## 使用

更新支持此接口的 Aide 后，客户端连接时默认启动索引后台更新，每十分钟检查一次官方市场。网络失败继续使用已验证的磁盘缓存或随宿主提供的旧目录；查询不等待后台网络请求，也不会把需求发给商店。宿主退出时停止后台循环。

在「插件 → 市场」输入需求，点击「按需求匹配」，可查看匹配插件、命中词与安装/启用状态。自动安装默认关闭。「允许 Aide 自动安装所需插件」是当前 Aide 实例的持久授权，作用于其各工作区；工具调用自身的审批、沙箱、代理工具白名单和设备权限仍然生效。

正常任务开始时，宿主用当前需求在本地匹配已启用插件。模型始终可用一个精简的 `route_plugins` 发现工具：

```json
{"query":"连接 SSH 设备并保存日志"}
```

结果最多五项，仅含 ID、名称、精简摘要、命中词及可安装状态。匹配到的启用插件会在下一模型轮次提供完整工具定义。缺少能力时，Aide 可以使用返回的 ID 主动请求安装：

```json
{"query":"连接 SSH 设备并保存日志","installId":"terminal"}
```

只有用户已开启自动安装，而且插件是官方市场中匹配、公开、兼容且尚未安装的条目，才会下载、校验并安装启用。默认关闭时仅推荐，用户仍可从详情手动安装。不自动购买私有插件，不升级或覆盖现有插件，不重新启用用户停用的插件，不自动运行 pip/npm 补装依赖。

使用已有的市场安装流程，固定目录修订、插件版本和 SHA-256，验证包大小、ID、版本、工作台声明和加载探针；发布到注册表前再检查授权代数、工作区身份、锁屏代数、沙箱与插件状态。授权开关关闭再开启也会使此前正在下载的自动安装失效。任务取消会中断下载；已完成的安装不会自动回滚，用户可从插件管理中移除。

已选插件的完整 schema 最多保留六个插件的窗口；后续发现新插件可替换最早选中的插件。任务保存插件 ID，暂停恢复后重新从当前启用状态加载，停用或工具禁用不被路由绕过。路由仅控制给模型披露的工具，不是新的执行权限边界；既有工具调用、计划节点和审批仍走原有服务器检查。

## 上架元数据

官方商店每次构建自动为全部条目生成 `routing` 字段与独立 `routing.json`。listing 可以显式提供：

```json
{
  "routing": {
    "keywords": ["3D建模", "模型预览", "装配"],
    "extensions": [".stp", ".step"],
    "summary": "预览与编辑三维零件，查看装配关系。"
  }
}
```

最多32个不重复关键词，每个96字节；最多16个合法小写扩展名；摘要最多1024字节。默认生成使用 ID、名称和现有场景别名；新插件发布者应补充具体场景/同义词，以提高匹配质量。构建与 Pages 验证拒绝过期索引。新增或下架插件后只需更新商店，不逐次修改宿主市场代码。

宿主消费固定修订的已验证 `catalog.json` 内的 `routing` 字段，避免路由文件和安装目录版本混用；独立 `routing.json` 同时公开供其他客户端使用。目录、描述与查询返回值始终是数据，不是指令或授权。匹配采用确定性关键词、扩展名、插件 ID/名称和本地工具名，不进行额外模型调用；它不是任意自然语言的语义理解保证。未命中时模型可换更具体的查询，或用户手动选择插件。

## 接口与数据

- `GET /api/plugin-routing`：当前自动安装授权、代数、索引修订和条目数，启动默认后台刷新。
- `PUT /api/plugin-routing`：`{autoInstall,generation}`，代数不匹配返回409；只接受经过宿主鉴权和同源检查的用户请求，`route_plugins` 不能修改此开关。
- `GET /api/plugin-routing/search?query=...`：1–2048字节需求，仅读取本地快照。
- `route_plugins({query,installId?})`：模型发现/选用插件，受管理员禁用和代理白名单限制；受限代理不能自动扩展安装权限。
- `config/plugin-routing.json`：当前实例授权与单调代数。文件损坏不授权自动安装。
- `cache/plugin-market/catalog.json`：复用已有的受校验官方市场缓存。

只发送被选中的完整工具定义，系统提示不再罗列所有插件工具名称。大工具 schema、执行结果、历史消息仍会消耗 token，因此不能承诺固定比例或总量上限。停用路由工具不改变插件的手动工作台/文件预览功能。
