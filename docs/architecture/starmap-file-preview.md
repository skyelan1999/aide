# 星图文件预览与原文位置

普通点击文件预览复用当前标签，通过既有只读文件页展示支持的格式，并提供返回星图入口。返回地址只接受同源星图路径及 channel、code 参数。星图离开前保存现场，不请求浏览器弹窗许可，默认 CSP 的 `frame-ancestors 'none'` 保持不变。

纯文本提取块、检索命中及重新核对的引用返回结构化 `line` 字段，空行与 CRLF 均计入源行号。Office 页、段落、单元格不伪装成文本行。预览携带原始文件的完整 SHA-256，复用文件页现有 `codeHash` 校验；文件变化时不跳到旧位置。

明确移除的来源、节点或已变化的目标身份，使当前检索片段和继续检索游标失效；无关的渐进扫描更新保留有效命中。来源暂不可读不等同于移除。用户需重新探索已失效结果，而不是把旧片段当成当前检索。
