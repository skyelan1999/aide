# aide v0.1.19.0-RC1

## 新增与改进

- 文件工作台可浏览、打开和保存工作区与引用中的声明格式，保留宿主确认、只读、来源身份和版本冲突检查；支持 Professional Resume 0.1.1 与 MapCanvas 0.2.1 的配套文件通道。
- 自选本机目录由原生助手持有真实目录对象，通过本机文件桥接提供 Docker 命名卷，保留 /mounts/<id> 使用方式，避免准备后替换路径导致目录越界。
- 新增授权 SSH 文件 checkout/commit，配套 SQLite 1.0.3 的停写文件快照与 StarLink 0.1.6 的 AI scope 星图；Office DOCX 结构、评论/resolve 和文档/图片附件绑定所选远端来源。
- 保留本周期已合入的多环境协作、会话时间线与运行中插话、附件独立发送、长粘贴转附件、大 Markdown 按需读取、插件受控文件/图片通道与原生电脑控制改进。具体范围见同版本使用与迁移说明。

## 修复

- 修复上下文预检按固定预算保留历史导致压缩后仍拒绝可容纳请求；按当前请求的实际剩余窗口保留历史。修复需求与阶段文档索引截断 UTF-8 分隔符造成标题乱码。
- 修复 Windows 原生启动器与 SDK 宏名冲突；嵌入助手的依赖许可从真实 vendor 源文件收集，保留第三方许可、NOTICE、PATENTS 与原始摘要。对应 #862/#863/#864/#865。
- OpenJPEG fallback 从固定原生源码、补丁和编译器重建；修正分配失败所有权、数值运算和 HT 解码边界，提供可复现构建及原生 sanitizer 回归。
- Markdown 向量 PDF 导出保留可检索文字、表格和独立图像，嵌入附件可由标准附件面板发现并独立恢复校验。
- 修复 Go 索引作用域、AI 隐藏引用与旧缓存、Unicode 匹配、默认工作台路由、锁屏/取消时文件发布和多项 SSH/预览边界。
- 修复及处置记录对应 #854/#855/#856/#857/#858；#776 的历史浏览器退出未重现，原始原因未知，不作为本次已修复崩溃宣传。

## 升级影响

- 请下载与 Linux Docker 引擎架构一致的完整包，核对 SHA256SUMS 后使用包内启动入口。日常 start 不编译；源码安装更新后须显式 build。
- 更新原生启动器与目录助手必须配套；仅替换容器或保留旧助手不能获得目录对象固定保证。自选目录身份改变会拒绝，需要明确移除并重新选择；原工作区、数据和既有全局挂载不因本功能迁移删除。
- 主程序不捆绑或自动升级公共插件。SQLite 1.0.3 与 StarLink 0.1.6 已独立发行，市场最低宿主为本版；先升级主程序，再升级插件。其他公开包以本次冻结市场清单为准。
- 升级前备份配置与数据，保留旧包和镜像，使用既有 A/B 健康检查与回退。源码安装不启用发行自动升级。本轮发布不自动重启维护者本机生产服务。

## 已知问题

- 目录桥接使用有界 soft NFS 超时，宿主休眠、助手退出或磁盘错误可产生 I/O 失败，须重读确认保存结果。nolock 不协调宿主其他数据库写入；特殊文件和其他用户所有权变更不支持。Windows 自选目录、TCC、网络盘和热拔插的完整物理设备验收仍未完成。
- SQLite 远端操作是乐观文件快照，不是分布式数据库锁或跨槽原子事务。须停止外部写入并完成 WAL checkpoint，直到调用结束保持停写；每文件及调用合计64 MiB。非空 WAL/journal 拒绝。
- 星图覆盖范围和静态关系不能证明资料不存在或程序已运行。模型审查不是测试，1X至10X容量不保证等比例提速，摘要仍有损。
- 当前公开包的实际安装/功能、双架构、Go终态、宿主、48格浏览器和新装生命周期以本标签 RELEASE-VALIDATION.json 为准。条件跳过、模拟桥接、Linux WebKit 和合成资料不替代真实客户硬件、原生 Safari 权限或付费提供商验收。
- 历史更宽 SSH 套件中的几项失败在干净源码基线也存在；单项 SSH 修复收据没有宣称全部历史场景通过。正式发布仍须本提交完整 Delivery 全部门禁通过，不能跳过失败放行。
