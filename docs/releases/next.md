# aide 下一次周更草稿（尚未发布）

正式周更时，使用 scripts/version.sh 升版后，将本文件整理为对应的 `docs/releases/<准确tag>.md`，标题改成准确的 `# aide <tag>`。发布门禁不接受本草稿替代正式版本说明。

## 新增与改进

- 普通运行镜像不再继承 Go、C/C++ 编译工具链，保留 Python、Node、Git/SSH、Office/DXF 与离线语音运行依赖。
- 同一版本分别提供 ARM64、AMD64 普通包及可选开发工具包；开发包支持离线导入，包含 Go、C/C++、make、pkg-config、npm。
- 主线公开 Release 改为每周一次，公开 RC 也计入。日常 main/PR 的测试和候选构建继续执行，候选不等于正式发布。
- 设置中的账户余额卡片可聚合插件提供的货币余额或百分比额度窗口，按币种/额度类型分开显示；缺失能力不当成零。此项已在主线实现，尚待纳入后续正式版本。

## 修复

本周最终合入的修复应按实际提交汇总，不能把候选计划写成已经发布的能力。已在上一版发布的启动器修复仅作为保留项，不重复声称为本周新增修复。

## 升级影响

普通容器不再直接提供 Go/C/C++/npm 编译命令。需要编译时使用可选开发工具包；当前助理不会自动将命令转发至工具包。工作区、会话、账户配置和数据挂载不迁移。

## 已知问题

最终正式发布前需填入本轮双架构原生构建及完整验收结果。既有 ARM64 本地受控比较为 582.4 → 359.7 MB（减少 38.25%），不能替代下次正式资产的实际大小。开发包另行下载，两个离线包会重复携带共享镜像层。
