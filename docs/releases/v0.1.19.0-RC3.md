# aide v0.1.19.0-RC3

本版本以正式 GitHub Release 交付，沿用项目的 RC 编号。与 v0.1.19.0-RC2 相比：

## 新增与改进

- 工作台前端模块陆续迁移到 TypeScript；运行期 JavaScript 仍由构建流程生成并核对。更新工作台交互、会话连续性及插件兼容性。
- 更新插件市场使用入口。仅对官方目录及其包允许显式配置代理，第三方来源不复用这一授权。
- 公开发行提供 Linux AMD64 和 ARM64 运行包，以及分别下载的开发工具包。公开插件在独立环境安装验证，不预装到发行镜像。

## 修复

- 将已配置的私有 pip 索引凭证经 BuildKit secret 传递；默认 Compose 不再隐式转发宿主 pip 索引。已有启动器仍接受不含凭证的公开索引覆盖。
- 修复干净安装时源码与发行运行模式的识别，以及生成媒体准备目录的问题。
- PDF 的 JPEG 2000 预览要求有效且唯一的顶层 JP2 Header；修复覆盖浏览器检查与原生 OpenJPEG 解码入口。
- 升级 go-billy 依赖以纳入两项已公开修复，并将非加密缓存标识改为 SHA-256。

## 升级影响

- 私有 pip 源请使用启动器的 secret 文件配置，不要把带凭证的索引 URL 放进 Compose 构建参数。参见[启动器构建说明](../architecture/launcher-contract.md)。
- 升级前备份本地工作区与应用数据；保留原有挂载路径。下载后可用发行资产内的 SHA-256 清单核对包。
- 需要 Go、C/C++ 或 npm 构建工具时使用对应架构的可选开发工具包；不把普通运行包视为开发镜像。

## 已知问题

- Windows 本机听写不在本次发行范围。Windows 真实显示缩放、对比主题及额外桌面集成仍有后续工作，自动化通过不等于实机验收。
- JPEG 2000 边缘格式兼容性仍有待复核，详见 [#915](https://github.com/skyelan1999/aide/issues/915) 等未关闭的跟踪项。
- 本次仅豁免已列明的存量待办，不标记其为完成；其他发行验收、源代码和产物校验保持不变。
