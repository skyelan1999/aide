# aide v0.1.18.0-RC3

## 新增与改进

- 配套 Terminal 1.6.0：复制会话配置或创建独立连接副本，可复用同一个已部署中继；副本使用独立连接、PTY、输出和日志。
- Telnet 支持直连和中继、IAC 协商、终端类型、窗口尺寸和 NVT 行尾；复制不保留密码，不重放命令。
- 独立设备 SSH 支持显式、非信任模式的 X11 转发，包括中继连接；运行镜像增加 xauth，仍需用户已有且可认证访问的 X Server。
- 发行门禁为当前 Terminal 原始 ZIP 增加实际 App/daemon 安装、复制、Telnet 与动态发送策略断言；运行镜像及导入后的镜像都检查真实 xauth。

## 修复

- 复制连接使用保存的规范身份和私钥引用，保留隐藏会话及跨工作区隔离。
- 工作区 SSH 使用 inode 固定的短 ControlPath，避免长私有状态目录超过 Unix socket 路径限制，不改接已有 SSH 主连接。
- 展示所有有内容的终端会话分组；修复取消 Telnet 连接后迟到结果恢复连接、跨块 CRLF/Unicode 输入和禁用发送后的执行边界。

## 升级影响

- 请先升级到本次 Aide RC3 或更新运行包，再安装 Terminal 1.6.0。市场的最低代码兼容门槛仍为 RC2；RC2 源码标签保留追溯，本轮运行包从 RC3 发布。
- 公共插件继续独立分发，Aide 镜像不捆绑公共或私有插件。开发工具为可选 SDK，默认运行镜像不带编译工具链。
- 升级前备份数据和会话状态，保留旧 Aide 和 Terminal 1.5.3 安装包。停止或升级插件会断开连接，不会自动重连或重放输入。
- 本轮发布不自动重启维护者本机生产服务。使用现有 A/B 升级与回退流程，不通过删除数据目录处理升级。

## 已知问题

- X11 需要可从 Aide 运行环境访问的 DISPLAY、私有 Xauthority、远端 xauth 和允许转发的 sshd；不自动安装 X Server 或放宽访问控制。
- 真实 Linux Xvfb、xauth、OpenSSH、X 客户端的直连及中继窗口测试已通过；这不能代替 macOS XQuartz、Windows X Server、客户设备或物理串口验收。
- 插件额外验证了三套真实主题的 12 个 Chromium 桌面/窄屏格，桥接和工作区资料仍是夹具。全局三浏览器 48 格矩阵覆盖 blue/comfort；Linux WebKit 不等于原生 Safari。
- 条件跳过项、当前 30 个公开插件的实际安装与功能结果，以及双架构、宿主和生命周期结果，以同标签的 RELEASE-VALIDATION.json 为准；不把跳过或尚未执行的项目写成通过。

精确源码、构建提交和安装包身份以本次发行附件为准；发布状态以对应 GitHub Release 为准。
