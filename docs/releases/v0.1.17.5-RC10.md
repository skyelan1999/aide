# aide v0.1.17.5-RC10

## 新增与改进

为支持项目邮件简报的插件提供显式声明的 `project.messages` 只读能力。按当前工作区、项目编号/名称或项目文件引用匹配相关任务，并返回指定北京时间日期范围内的用户和助手会话消息及来源。新增本地消息时间，跨日回复按实际消息时间筛选；旧消息缺少消息时间时注明按任务时间。

## 修复

本地消息来源和时间元数据在发给模型前移除。旧会话中非字符串时间扩展兼容读取，避免仅因该字段导致已有会话被隔离。沿用 RC9 的正常升级就绪后自动备份及更新完整性基线机制。

## 升级影响

主服务升级会短暂重启，沿用原数据与工作区挂载，不迁移或重写项目文件。ProfessionalProject 0.4.15 通过私有插件包独立升级，不包含在公开主程序镜像或附件中。简报功能提供可复制文本和邮件文件，不自动发送邮件，也不调用付费模型。

## 已知问题

消息匹配依赖明确的项目引用，不进行语义检索或跨工作区搜索；单次最多31天、100条及48KB，截断和省略会标明。消息中心即时通讯不在本版会话提取范围。当前进度和风险是生成时快照，不是历史快照。Windows 原生 Docker Desktop 升级和外部邮件客户端打开本轮未在本机实测。
