# aide v0.1.17.5-RC12

## 新增与改进 / Added and improved

- 主程序新增只读市场发现工具 `browse_plugin_market`。未安装任何插件时，主会话和助理也能浏览目录、按关键词搜索及查看详情，返回版本、兼容性、安装和启用状态。
- 市场发现复用已校验目录与缓存，支持离线浏览、分页和显式刷新；缓存过期和刷新失败如实展示。查询不安装、启用、升级或购买插件，也不改变权限。

Built-in market discovery is available to main chat and the assistant before any plugins are installed. It lists, searches and inspects validated catalog metadata with bounded pagination, installation/compatibility state and honest freshness diagnostics. Discovery never installs plugins or expands permissions.

## 修复 / Fixed

- Windows Release 启动器不再用包内默认目录覆盖 `.env` 的工作目录、资料目录及本机目录根设置；工作目录、自动系统文档和本地引用共用正确的挂载范围。
- 修复端口调整和更新代理丢失额外目录 Compose 挂载覆盖的问题，并补齐 Windows AMD64 启动包中的端口监控脚本。
- 修复 Windows 手动 A/B 切换忽略可选列占位符、含空格启动路径传参错误，以及等待常驻子进程导致切换无法结束的问题。
- 更新代理恢复异常退出后的锁，校验目标容器实际镜像及健康状态；支持从本次已校验导入回执解析 Docker containerd 改写的本地镜像 ID，失败恢复原槽。

Windows launchers preserve explicit directory settings and additional Compose mounts. Both Windows architectures include the port monitor. Manual slot activation handles optional fields and paths with spaces, waits only for the launcher process, checks the running image and health, and recovers stale ownership. Verified containerd imports resolve their canonical local image ID; failed activation restores the previous slot.

## 升级影响 / Upgrade impact

- 完整运行包与开发工具包仍独立提供，请选择与 Docker 引擎架构对应的 ARM64 或 AMD64 包。不会捆绑或预装任何插件。
- 本次 Windows 修复包含宿主机脚本；已有 RC11 安装不能只替换 Docker 镜像来获得这些修复。请先保存工作并备份启动目录，保留 `.env` 和 `.aide-data`，更新完整包中的启动脚本。若旧更新代理仍在后台运行，替换脚本后重启一次 Windows，再通过 `start.bat` 启动。
- 其他盘符仍须显式配置共享目录和权限；本次修复不自动开放其他磁盘。应用内切换会短暂中断运行任务和手机连接，两槽继续共享原有数据。
- 本次为所有者明确要求的补发版本，常规每周发布节奏不变。发布不会自动替换本地 9999 服务；私有研究实现和资料不在公开版本中。

Use the full runtime or separate developer toolbox matching your Docker engine architecture. Existing RC11 Windows installations must update host launcher scripts as well as the application image. Back up the launcher folder, preserve `.env` and `.aide-data`, replace the scripts from the complete package, and restart Windows once if an older background updater is still running. Other drives retain explicit sharing/permission requirements. This owner-requested supplemental release does not change the normal weekly cadence or automatically replace the installed 9999 service.

## 已知问题 / Known limitations

- 市场搜索是名称、描述与路由关键词匹配，不宣称向量语义推荐；宿主兼容性元数据不能代替指定操作系统的插件运行验收。
- 通话硬件、付费模型和用户 Windows Docker Desktop 的完整升级/目录选择实机验收不在本轮本地隔离测试范围。Windows PowerShell 5.1/7 的代理回归使用隔离的 Docker、HTTP 和进程替身；不能把它描述为原生 Desktop 全链路通过。
- 插件包、许可证和私有实现由各自渠道管理；主程序不会因为市场查询而下载或执行其代码。

Search uses catalog keywords rather than vector semantics. Compatibility declarations are not OS execution acceptance. Host-agent regression uses synthetic Docker/HTTP/process adapters; paid providers, microphones/cameras and user Windows Docker Desktop end-to-end acceptance are separate. Plugin code and private implementations are not bundled.

## 验证 / Validation

本地已完成市场与助理定向 race/vet、零插件主会话及助理工具循环、官方 29 项目录查询，以及 Windows PowerShell 7 的目录与切换代理回归。发布还须通过当前源码完整门禁、Windows PowerShell 5.1/7 CI、双架构镜像构建与导入、启动冒烟、发布包隐私审计及远端 SHA256 核验；结果以最终发布回执为准。

Local targeted verification includes race/vet, empty-registry main/assistant tool loops, the live 29-entry official catalog and PowerShell 7 directory/switching regressions. Full gates, Windows 5.1/7 CI, native builds/imports, startup smoke checks, package privacy audits and remote digests are required for publication; the final release receipt records their outcome.
