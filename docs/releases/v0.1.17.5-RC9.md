# aide v0.1.17.5-RC9

## 新增与改进

正常镜像升级后自动维护程序完整性基线，保留上一份基线以便恢复。完整包同时适用于首次安装和升级，用户数据继续使用原有数据卷。

## 修复

修复正常升级后仍沿用旧程序摘要、持续显示 integrity=degraded 的问题（#60）。只有镜像构建摘要与正在运行的二进制一致、构建身份变化、数据完整性正常且应用启动就绪后，才备份并原子更新基线。启动失败、摘要异常或数据异常不会自动覆盖旧基线；正常回退执行相同验证。

## 升级影响

升级会短暂重启主服务，保留原有会话、设置、项目及插件数据。新机制随本版 Linux ARM64 / AMD64 镜像生效；镜像不包含私有插件或用户配置。升级前仍应保存当前草稿并保留旧镜像。

## 已知问题

旧版本镜像及裸 go run 不具备本版的自动基线转换能力。镜像内构建摘要不替代发行来源、安装包摘要和镜像身份校验。本版隔离升级、失败启动、摘要异常与回退已验收；Windows 原生 Docker Desktop 的实际升级未在本机验收。
