# aide v0.1.17.5-RC11

## 新增与改进 / Added and improved

- 补齐主工作台、知识星图、手机采集、恢复与导出、文件查看器和设置的英文界面。新增 893 个英文词条，目录共 4,136 个唯一词条。
- 新增 13 篇当前英文操作与开发指南，更新英文文档索引和交付包中的文档入口。历史验收与许可证保留原文。
- 回答下方的复制、朗读、重试、继续和反馈使用图标，保留英文提示、无障碍名称和键盘焦点。
- 简化桌面标题栏，并统一工作区状态指示的颜色、光晕和尺寸。

English coverage now includes the workbench, knowledge map, mobile capture, recovery/export, file viewers and settings, with 893 new translations and 4,136 unique catalog keys. Thirteen current English operating/developer guides are linked from the English documentation index and delivery packages. Reply actions use accessible icons, and the desktop header and workspace status indicators are simplified.

## 修复 / Fixed

- 修复动态文案回退时未展开编号占位符的问题，并检查编号及命名占位符的完整性。
- 修复语言切换后文件权限说明、文件传输和侧栏调整标签未刷新的问题。
- 补齐知识星图默认来源名称、工作流节点状态及确认按钮的翻译，保留自定义来源、流程及节点名称。
- 更新独立页面资源版本，避免缓存继续加载旧文案。

Fallback messages retain substituted values. Language changes refresh owned file/accessibility labels; default knowledge sources and workflow state/action labels are translated without rewriting user names. Standalone asset versions are refreshed.

## 升级影响 / Upgrade impact

- 使用与设备架构对应的完整运行包；开发工具包单独提供。用户目录、会话、模型配置、文件内容和协议标识不因语言切换而翻译。
- 本地已安装服务不会因为创建 GitHub Release 自动替换。请保留原有数据备份，并遵循安装目录中的启动与升级说明。
- 本次为仓库所有者明确授权的一次提前发布；日常公开发布仍遵循每周最多一次的规则。

Choose the full runtime package matching your architecture; development tools remain a separate download. Language selection does not translate user data, model output or protocol identifiers. Publishing a Release does not automatically replace an installed service. This is a one-off early publication explicitly authorized by the repository owner; the normal weekly release cadence remains unchanged.

## 已知问题 / Known limitations

- 插件各自维护界面和文档；宿主不会自动翻译第三方插件或模型、服务商返回的内容。
- 历史评审、任务记录和详细中文技术附录保持原有语言与证据状态，不能视为新执行的英文验收。
- 本次界面实测使用隔离的合成数据，未调用付费模型、麦克风或摄像头，不构成新的语音硬件或服务商集成验收。

Plugins own their translations. Historical evidence and canonical technical appendices retain their original language. Browser acceptance used synthetic isolated data and did not exercise paid providers, microphones or cameras.

## 验证 / Validation

当前代码的本地完整门禁通过 146 条检查，包括隔离 Go race/vet；文档检查覆盖 419 个 Markdown 文件和 1,441 个本地链接。实际浏览器检查覆盖双向语言切换、跨标签未保存编辑与任务草稿保留、390 像素布局和回答图标。发布包另行执行双架构构建、镜像层审计、运行冒烟与远端摘要核验，并随交付提供校验文件。

The current-input local full gate passed 146 commands, including isolated Go race/vet. Documentation validation covered 419 Markdown files and 1,441 local links. Real-browser checks covered both language directions, cross-tab unsaved editor/task drafts, 390px layouts and reply icons. Release package acceptance separately builds both architectures, audits image layers, runs runtime smoke checks and verifies remote hashes; checksums accompany the downloads.
