# Knowledge map: search, history and evidence

[English documentation](README.md) · [Canonical technical reference](../architecture/knowledge-map.md)

Open the knowledge-map action from the file panel to connect the current conversation/workspace. The independent page explores actual indexed files, conversations and code. It does not synthesize fictional nodes. Source filters, visibility, lock state and workspace identity continue to apply.

Use Nodes/Names for indexed metadata, Document text for literal source-text search, or Document RAG for excerpt retrieval. Literal search does not call a model. RAG defaults to local keywords; optional vector/hybrid retrieval requires explicit embedding configuration. Selecting AI sends bounded source excerpts and metadata to the configured provider; review the in-page disclosure. User documents, paths, node IDs and model answers remain in their original language.

Code view distinguishes declaration hierarchy, imports, static name candidates and optional snapshot type bindings. Incoming-edge absence does not prove a symbol is unused. Dynamic dispatch, reflection, dependencies outside the index and unresolved paths can be missing. Depth controls outward focus; reverse traversal retains the original relationship direction. Evidence paths describe the current index rather than runtime execution.

Index scans have count, depth, time, size and extraction budgets. Pending or unreadable sources are reported. Partial coverage cannot establish that a complete repository or document has no matches. Automatic deltas preserve the last complete map while updates continue. File preview revalidates source identity and content/location fingerprints.

History saves observations of indexed knowledge, not complete filesystem versions or model memory. Compare two observation times to see node/relationship changes, saved excerpts and explicit references. Evicted observations or incomplete excerpts remain unknown. A node removed from an index does not imply its file was deleted.

Manual topics align selected original wording across observations. They preserve markers and explicit references rather than rewriting source text. They do not prove a conclusion is correct, a model read a citation, or an unobserved conclusion was withdrawn. Disabling a topic keeps its markers. Historical text never becomes a current source merely by comparison.

The astronomical scene is a graph visualization: star size/color reflect valid relationships; gateways follow indexed inter-system links; dense regions may appear as black holes. Scene depth, mass and infrared false colors are not physical measurements. Motion and reduced-motion settings affect presentation only. The handbook explains the optical approximations and evidence limits in both languages.
