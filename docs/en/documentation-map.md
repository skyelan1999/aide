Detailed Chinese architecture appendices, dated incremental PRDs, task JSON, review reports, release archives and old screenshots remain source/evidence references with their original identity. They are not relabeled as English instructions or newly verified results. Protocol/code examples retain machine identifiers. Licenses retain their original wording. Installed plugins own their independent documentation; host localization does not translate their private internals.

Screenshots illustrate only the UI actually captured at the recorded time. Source availability, rendering, save/reopen, real provider integration, remote-host execution and published artifacts are separate acceptance levels. Current release validation is recorded in its own task and release notes.
