# 实际界面演示手册

本手册按真实操作截图编排，基线 `0fef6411`（2026-10-17）。环境、示例数据和原图校验和见[截图证据](ui-evidence.md)。演示不使用虚构的 AI 成功回答；没有模型密钥的页面明确展示未配置状态。

## 1. 确认工作台与目录

![开始新的探索](images/current-20261017/01-workbench.jpg)

通过自己的 `start.command` 启动并登录。默认端口由 `.env` 的 `AIDE_PORT` 决定；截图端口只属于本次专用实例。左侧选择工作空间，右侧文件列表确认项目内容，再开始任务。

![文档目录绑定](images/current-20261017/02-workspace.jpg)

点击工作空间卡片，查看“自动系统文档”。截图的 `/workspace/docs` 是示例；实际交付应选择自己的目录。工作目录、自动系统文档、缓存是三个独立位置。不要为获得写权限把只读引用改成工作目录。

## 2. 查看引用与实际文档

![引用与锁](images/current-20261017/03-references.jpg)

文件 → 引用，检查来源启用、眼睛图标和可写锁。示例 Reference library 为只读，自动系统文档有独立固定条目。给模型指定引用目标时，说明来源名称及相对文件路径，先确认允许写入。

![实际 Markdown 文件](images/current-20261017/12-markdown.jpg)

打开 `example-notes.md`，查看标题目录、表格和代码。截图确实读取了该示例文件；未点保存或导出，不把预览描述成导出成功。

## 3. 配置模型，再运行真实任务

![模型提供商](images/current-20261017/13-models.jpg)

模型设置 → 展开提供商 → 填本人密钥 → 获取或填写模型 → 保存。不同提供商的模型和命名密钥分别维护。本轮未填写密钥、未点击模型获取，截图只证明配置入口。

完成配置后可附加示例文件，发送“阅读此文件，给出来源并生成说明文档到自动系统文档目录”。观察任务执行、提案、审批和系统应用回执，再从文件面板读回结果。**这一模型执行步骤为后续演示操作，本轮未执行，也没有对应伪造成功图。**

## 4. 检查插件工坊与管理授权

![插件工坊](images/current-20261017/11-plugin-workshop.jpg)

插件面板搜索 `plugin-authoring`，查看已启用工坊与工具说明。让 AI 制作插件前提供用途、输入输出、权限和验收样例；生成的包先检查、下载并审阅。

![管理权限](images/current-20261017/05-management.jpg)

主设置 → AI 管理权限。助理/aide 各有插件和引用两个管理开关。开启权限不等于批准某次管理变更，最终提案仍由用户确认。本轮四项保持关闭，没有为截图修改访问权限或安装新插件。

## 5. 进入工作统筹与百炼语音配置

![助理设置](images/current-20261017/06-assistant-settings.jpg)

身份验证后助理在页面开启期间统筹工作；麦克风入口只控制收听，不必再找陪伴开关。代审交办任务是另一个设置项，不等于可代答所有邀请。

![百炼配置](images/current-20261017/07-qwen-tts.jpg)

设置 → 语音助理 → 语音引擎选择百炼，按密钥所属地域选择兼容模型和音色。保存后先试听，再核对真实回复播放和本人说话打断。截图目录为内置回退列表；本轮没有合成、播放、付费或麦克风操作，不能据图确认音质、延迟和打断效果。

## 6. 使用消息和原有提醒

![消息的启用条件](images/current-20261017/08-message-settings.jpg)

设置 → 账户先填写账户名称，再到设置 → 消息启用设备通信。联系人添加使用短码查找，核对完整身份后由双方同意。群组、通话和文件分别确认；不要因已是联系人就省略文件接收确认。

![原有提醒仍在消息内](images/current-20261017/10-reminders.jpg)

顶栏消息 → 提醒，查看示例事项、搜索、范围筛选和完成/编辑按钮。该提醒是专用实例真实保存的数据。跨电脑联系人、群组、语音和断点续传需双设备另验，不用空白列表替代运行结果。
