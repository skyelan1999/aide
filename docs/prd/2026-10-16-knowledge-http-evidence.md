# 按钮到服务的静态证据链

对应原连续工作目标的“星图路径探索”，不是新增运行时追踪功能。基线 main `584aa9b`。现有 HTML、事件注册、HTTP 请求和 Go 路由之间缺少桥接，仅有函数调用和文档引用不足以完成该要求。

目标链为：真实 HTML 按钮 → 当前页面加载脚本中的事件绑定 → 回调函数 → 字面 HTTP 请求 → 唯一匹配的 Go 路由 → 处理函数及已有函数调用关系。每段保留原文件、内容指纹和位置，标明静态声明、选择器候选或路由候选。路径面板必须清楚展示这些等级，不能称为执行记录。

先复用产品拥有的 AST 解析器：JS 提取直接 DOM 事件绑定及字面 fetch，使用词法绑定排除被遮蔽的 document/fetch；HTML 使用只解析源文本的标准解析器；Go 使用 AST 识别标准 HTTP 路由注册。所有解析不加载、导入或执行工作区代码。动态 URL、动态选项、无法解析的回调、歧义目标及不支持框架须给出有界诊断，不补造关系。

关联受同工作区、根、来源和区域限制；HTML→JS 必须有实际脚本引用，HTTP→Go 必须保留方法、路径和唯一性。跨项目同名 URL 不能自动合并。不以函数同名、字符串搜索或目录包含作为调用证明。

预算沿用代码文件数、字节、解析超时、符号与总边数上限，新增每文件每类 web 记录256条上限。取消、锁屏、工作区/索引版本切换继续拒绝旧结果。仅在代码视图扩展这些关系。

验收须包含真实临时项目从索引到 HTTP 路径接口的完整多段链、每段源定位，以及遮蔽/动态/重复路由/跨来源/未加载脚本的反例。页面实际验收和完整认证 Safari 分别记证据，后者沿用人类暂缓决定。完整full、独立main门禁、本机启动、离线包与回滚收据仍需逐项执行。

实现分阶段保留在同一任务中：解析证据 → 图构建与诊断 → 路径呈现 → 实际联动和发行。单个解析器测试通过不代表本需求完成。Windows由用户验收，真实向量测试暂缓。
