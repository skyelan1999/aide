# 服务商计价与余额支持插件

用户授权：将 DeepSeek 计价与余额从 Aide 内置逻辑拆为插件；增加阿里百炼同等插件。费用支持按提供商、密钥、模型分别设置与归属。两个用户指定公开仓库保留独立源码，本次不上传市场或 Release 附件，不访问真实账户。

## 边界

Aide 保存通用 Token 用量、计价快照、手动单价与加密凭据。插件仅声明 `providerSupport: {protocol: 1, catalog: "provider-support.json"}`，提供静态 JSON 价目表、精确 HTTPS 服务地址、模型别名、整请求输入长度档位、缓存命中单价、思考输出单价、峰谷日历，以及只读余额接口适配类型。插件不注册 AI 工具，不接收模型 API Key 或 RAM AccessKey。价目表不在运行时联网更新，版本与来源随插件更新。

仅安装、启用、无启动错误且唯一匹配的插件生效。JSON 限 128KiB，通过目录句柄读取并限制于插件目录；文件缺失、损坏、目录逃逸、重复匹配均回到手动费率。匹配要求 HTTPS、精确域名与路径，不把 DeepSeek 模型在第三方平台的价格套用为 DeepSeek 官方价，也不将百炼北京地域价格用于国际地址。

## 计价

单价优先级：指定提供商＋密钥＋模型 > 提供商＋模型（所有密钥） > 匹配插件价目表 > 旧版手动模型价 > 全局默认估算价。0 是有效免费单价。清除指定范围覆盖后恢复继承。旧版模型单价与历史调用记录保留；修改配置、切换密钥、安装或卸载插件均不重算历史。

每次模型请求从请求配置快照提取提供商 ID、密钥 ID 和显示名称，不记录密钥正文。每次完成保存实际调用模型、用量、应用单价、规则版本、峰谷标记、费用与估算标记；按密钥及密钥＋模型汇总，旧记录无密钥身份的归为未知，绝不根据当前密钥补写历史归属。

阶梯价格根据整次请求输入量选取，并应用到整次请求。未提供缓存拆分时，支持缓存费率的模型按全部未命中估算。百炼缓存创建/模式折扣没有充分使用明细时不猜测，明确标估算；上游 reasoning_tokens 大于 0 时能确认思考输出；等于 0 不证明采用非思考计费模式，无法确定且两种输出价不同时按较高价估算。跨出内置节假日日历年份会标估算，不假装未来假期已知。账面费用是用量与单价的本地测算，不替代服务商最终账单、套餐或优惠抵扣。

## 余额与凭据

`GET /api/balance?providerId=&keyId=` 只在匹配插件启用时发起请求。无插件返回 `supported:false`，不发网络请求。DeepSeek 只把选中密钥的 Bearer 凭据发送到该提供商同一 HTTPS 主机。百炼使用固定只读 QueryAccountBalance RPC；固定中国站地址 `https://business.aliyuncs.com/`、API 版本 `2017-12-14`，不能通过插件声明改成任意操作。

百炼 RAM AccessKey 与模型 API Key 不同。`GET/PUT /api/provider-billing-credentials` 按提供商管理独立保险库条目；GET 只返回是否已配置，PUT 仅在保险库解锁时写入或清除，不回传明文。浏览器提交后清空密码输入，不写入 localStorage。默认阻止重定向，限制响应大小、超时，错误不反射带签名的请求 URL 或上游原始正文。余额只反映费用账户，可能含信用额度；多个模型密钥可以共用同一账户余额，不能理解为每个密钥独立钱包。

## 验收范围

正常功能与拒绝路径使用隔离数据、本地模拟 HTTP transport 和公开官方文档。真实账户余额、真实收费调用、套餐折扣、RAM 实际权限及物理 AMD64/Windows 未验证。生产服务不替换。完整浏览器与 API 验收结果见任务账本。
