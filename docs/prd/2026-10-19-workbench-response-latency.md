# 工作台交互响应优化

用户反馈使用反应有延迟。先处理已能复现的 UI 等待链路，不把接口、模型生成、渲染、宿主挂载混为一个指标。

- 设置面板点击即显示并聚焦关闭按钮。首次下载定义时显示加载状态；同一下载由多个打开动作共享。关闭／重开按序号归属，旧请求不重开或覆盖新面板；失败保留可关闭的错误提示，重新打开可重试。定义已缓存时同步构建控件。
- 会话子组折叠／展开只基于当前已取得的列表快照，不重新读取活动和归档列表。服务器数据仍由显式刷新、任务事件和原调用链读取，不添加长期过期缓存。
- 会话列表在 DocumentFragment 中构建后一次替换；内容、选中项、语言及展开状态均未改变时保留现有 DOM。助手入口仍单独核对实时状态。
- 列表读取按请求序号、工作区和令牌隔离，较旧响应不能覆盖最新一次。不同语言、登录身份、工作区和选择状态均会使旧绘制缓存失效。

不改变任务调度、模型输出、消息与文件格式、会话删除语义或安全检查。此轮不声称修复所有设备上的延迟，真实实例与未验路径见验收记录。
