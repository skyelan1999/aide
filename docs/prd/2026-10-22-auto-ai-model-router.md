# AutoAiModelRouter · MIT 插件与宿主扩展

用户需求：安装启用插件后模型栏顶部出现 Auto；多倍率按独立子任务选择已配置的不同厂家/API/模型并发；1X 按编排阶段切换；能力档案依据官方资料预置，运行期不联网更新，只按模型名称匹配。

插件携带版本化 capabilities.json、来源 URL/核对日期/能力摘要和明确标为维护者启发式的适配权重。官方不同评测不混成统一百分比分数。宿主只解释受限声明，不载入插件到 Go 进程、不向插件传密钥、不执行档案文本。仅一个有效启用的路由插件生效；禁用/卸载恢复手动回退模型。插件不默认启用 Auto，用户选择后按会话保存。

模型选择与左侧参数“自动路由”独立。会话保存 modelRouter=auto 和原手动模型作为回退；历史任务记录每次实际选择及原因。模型与提供商凭据仍来自现有设置和 SecretVault，不新增凭据存储。

只考虑已配置、可解析提供商且上下文/图片/工具能力满足本次请求的模型。名称使用明确别名精确匹配（忽略大小写及已知厂商命名空间），未知型号不猜测能力；可在插件设置显式填写别名映射。无候选时保留原模型并给出回退原因。API 错误不静默重试多个模型，防止成本与副作用失控。

1X 在每次编排/工具请求边界按任务角色重选，不并发，不重放工具；多倍率沿用现有只读子分析边界，为规划和每个独立子任务分别选型，主任务统一核验与最终答复。倍率是并发上限，不保证线性提速。工具权限、审批、取消、恢复、Token 统计与工作区代际约束不放宽。

验收：真实安装/停用菜单显隐和会话持久化；模拟多个独立 HTTP 提供商验证逐路真实重叠、各自模型和认证、1X切换、窗口/图片/工具约束、未知型号、损坏档案、停用、取消与无密钥泄露；不以模拟 HTTP 验收冒充真实厂家付费调用。当前日常实例不自动重启，公开推送/市场登记/Release 单独记录。

兼容边界：仅现有 OpenAI-compatible Chat Completions 地址；Anthropic/Gemini 需兼容网关。已知 GPT 推理格式转换 max_completion_tokens 并省略不兼容采样字段，通用网关推理强度取网关默认。未实现原生 Messages/generateContent。档案初始含4个官方来源模型族；不是动态模型大全。
