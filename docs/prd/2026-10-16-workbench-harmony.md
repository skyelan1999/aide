# 工作台协调性补充打磨

用户要求整体界面更协调，微调图标、边框、高宽与渲染，并支持动态背景。本轮沿用已有[工作台背景](2026-10-16-workbench-polish.md)，不重做会话运行逻辑。

- 修正601～700px断点：隐藏侧栏后仅保留主列；两行顶栏保持92px，与浮动文件面板起点一致。
- 统一设置项分隔与标题字号、工具按钮SVG比例；文件刷新、新建、关闭及设置关闭采用同一描边图标。
- 会话正文统一首尾间距、标题节奏、代码框边线及表格单元格间距；宽代码和表格在自身区域滚动。
- 外观 → 工作台背景沿用关闭／流光／本地素材，增加10%～50%背景强度，默认22%。这是装饰层强度，正文卡片仍使用主题表面色。
- 强度走 `aideUI` 本地偏好与跨标签同步，刷新恢复；调节仅改变遮罩，不更换媒体URL或播放器。旧偏好缺字段时回退22%，异常数值规范化。
- 素材沿用30 MiB上限与当前浏览器IndexedDB；后台、锁屏及减少动态效果时暂停／隐藏。没有增加远程素材加载或上传。

验收包括390、614、700、701、950、1024、1440px布局检查，六组主题、真实本地MP4播放、刷新恢复、减少动态效果以及媒体不重复加载。组件预览不代表完整认证工作台或Safari验收。历史后端未完成改动保留在原任务，不并入本轮界面交付。
