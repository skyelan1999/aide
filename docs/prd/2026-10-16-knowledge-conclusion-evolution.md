# 知识时光：结论与依据演变

承接原任务“按时间比较真实节点增改移除、历史依据与结论演变”。本次重点偏好尚未收到回复，先同时覆盖AI和文档两类；这是实现假设，不是用户新增授权或回答。基线 main `dc0cf72`。

现有历史只存节点、文本摘录与关系变化，不能把任何文件改动称为结论变化。目标是保留结论原话、来源类型、源身份、当次观察版本和引用依据，分别呈现文字变化、依据变化、位置变化及无法判断；不自动宣称事实正确、观点被推翻或文件已删除。

文档结论从明确标记的结论段落捕获，保留标题路径、源行范围、摘录指纹和截断状态。AI结论必须来自可归属当前工作区任务的assistant记录，用户消息、工具结果及混合压缩摘要不能冒充AI结论；记录任务、原始问题身份和回答阶段。标题相同不代表主题相同；只有可证明同一问题或显式用户对齐才连接演变，其他记录并列呈现。无标题的AI回答/用户选择片段及主题对齐仍在整体范围内，不能用只识别文档标题的版本替代。

依据必须关联当次历史快照中的真实引用及目标内容身份，保留静态证据等级。结论文字未变但依据内容变了需要独立显示；无法解析的引用、未覆盖正文和不可用来源明确提示未知，不等于没有依据。历史引用不能冒充当前文件。长文未保存的段落不能回填或伪造；现有8 MiB/32次历史约束保持，不引入全库额外读取阻塞渐进索引。

支持分阶段接入：有界片段捕获与比较→AI归属/问题对齐及历史依据→既有时间线API与页面→真实文件、会话、持久化和浏览器验收→full与main/镜像交付。阶段性“明确结论段”提取不是全部需求完成。旧快照缺少采集字段、来源截断、重复标题、工作区变化均不得被解释成结论新增/撤回。

验收包含：普通文件文字变化不产生结论变化；代码/引用/HTML中的伪标题不被识别；Unicode源定位与有界截断；不同问题、角色、工作区和重复标题不误对齐；结论与依据变化独立；旧历史/来源不可用保留未知；历史加密/保留/损坏及页面锁定隔离保持。最终通过实际索引/HTTP/磁盘重读与页面交互分别给证据，完整Safari仍按人类暂缓，Windows由用户验收，真实向量测试暂缓。

## 当前AI与依据阶段

AI记录采用加密历史私有侧录，不进入普通星图节点或模型资料载荷。只取当前工作区中可归属实际任务的assistant正文，排除工具调用、中间类型、用户文本及压缩摘要。提问身份按工作区和该任务实际用户输入序列计算；无归属历史、不同问题或重复任务身份不能自动连接演变。无标题回答保留原话并标记“未标记结论”，不自动升级为结论。每次最多32条、每会话4条，结论元数据编码输出64 KiB、输入256 KiB，角色/任务扫描亦有预算。

依据比较从两次保存的快照独立重建明确编号、Markdown链接与引用式链接。只从同一次观察中、同一文档或同一任务AI原文解析片段外的定义，不从混合会话正文、其他文档或当前文件补齐。不会在比较时读取当前文件或访问外链。文档相对路径限定原来源；AI相对路径须在当次快照唯一；显式来源路径保留来源身份。代码围栏、行内代码和注释里的例子不作为依据。复杂HTML、页内定位、缺失正文、歧义和预算超限明确保持未知。纯文本路径与语义依据关联不自动推断。

结果将结论文字变化与依据引用/摘录内容/可用性变化分开，即使结论原话未变，也能显示已保存依据变化。依据哈希明确属于已保存摘录或已索引代码；摘录范围扩大不直接冒充内容修改。每结论最多16引用，一次比较最多512引用、128条依据结果和512 KiB序列化输出；目标哈希输入每快照1 MiB。解析不证明模型实际读取，不判断结论正确或撤回，不把历史编号变成当前引用。

新增AI侧录使用历史载荷版本2，继续读取旧版本1；首次升级前按加密原件指纹保留独立0600备份，备份失败或原文件变化则拒绝替换。外层加密协议和32次／8 MiB保留限制不变。旧二进制拒绝未知载荷版本，避免写回时静默丢失AI字段。回滚二进制前需停止实例、另存版本2历史，再恢复对应版本1加密备份；旧版本不能直接写回版本2。未在生产执行该迁移。

## 历史正文扩展

当前开发版进一步保存可归属assistant消息的原始正文前缀，每条最多64 KiB；正文与用户输入共用既有256 KiB采集预算，不额外读取会话或文件。保留原始CRLF、Unicode、已保存正文指纹及原消息字节长度。仅当正文未截断且任务已完成时标记完整；输出中断、超长或预算不足不能被解释成完整答复。正文不因含有标题就全部成为结论，普通图与模型资料载荷也不增加这些私有内容。

该字段使用AI侧录版本2、历史载荷版本3；继续读取载荷1／2以及旧AI侧录。首次从旧载荷写入3前，保留 `.before-body-v3-<加密原件指纹前12位>.json` 的0600加密原件；备份损坏、符号链接或版本已变化时拒绝覆盖。旧二进制拒绝载荷3，不能静默丢掉正文再写回。回滚须停止实例、另存新历史并恢复对应旧格式备份；本阶段不在生产迁移。

正文总原始字节上限256 KiB，原结论元数据编码预算仍为64 KiB；为容纳JSON控制字符转义，AI侧录序列化上限2 MiB。历史最多保留32次观察；压缩封装采用下述独立物理与解码预算，达到任一预算时淘汰最旧观察，不承诺一定保留32次。

### 大星图留存与已有封装兼容

两次约7 MiB的图观察必须能保留并进行真实差异比较。历史封装 v2 在 AES-GCM 加密前使用 gzip 压缩，物理文件不超过8 MiB，解码后 JSON 不超过32 MiB，仍最多32次观察。载荷版本1／2／3和原有结论、正文、指纹语义不变，向量缓存的编码不变。

继续读取已有 v1 加密封装，也能读取已存在的 v2 压缩加密封装；读取不改写原文件。首次从 v1 写入 v2 前，将原加密字节以0600权限保存在 `.before-gzip-v2-<原件指纹前12位>.json`，版本已变、备份损坏或符号链接时拒绝覆盖。旧二进制可能无法读取 v2，回滚需先停止实例、保留新历史，再按对应备份与兼容二进制恢复；本轮不执行生产迁移或回滚。

压缩损坏、截断、多段／尾随内容和解压超额均拒绝读取并保留原文件。超额淘汰须准确累计 dropped，不捏造此前已被淘汰的观察。当前源码的专项和运行／发布范围见[同步后留存修复](../reviews/2026-10-17/timeline-retention-synced-main.md)。

人工主题来源列表额外提供每段最多4 KiB的历史正文片段，优先按换行分段，超长单行按UTF-8边界分段，选择仍用UTF-16校验。AI条目标明已保存／原消息字节数；文档只分段展示索引当时已经保存的正文，不额外读取当前文件。旧AI侧录没有正文时继续仅提供原有片段。保留原有首段令牌，新增正文片段不改变其身份。候选列表仍受每观察128项／256 KiB响应预算限制，可按节点筛选；选定片段不能跨段拼造原话。片段外定义按下文规则从保存正文解析，保存或解析不证明模型实际读取过依据。

### 引用定义与使用位置

使用固定版本的Markdown语法解析器识别实际链接及完整／省略／快捷标签引用和图片引用。按语法匹配标签大小写／空白与首个有效重复定义，支持定义在前或在后、多行标签／标题及容器内定义；未被使用的定义不算作依据。使用位置与定义位置分别保留，定义摘录最多2 KiB及完整已保存定义的指纹显示在历史依据区，不提供冒充当前来源的点击入口。

结论原话未变时，使用写法／目标／定义原文变化仍独立报告为引用变化；目标摘录或索引代码指纹变化独立报告为依据内容变化。仅移动相同定义或新增无关定义不算作依据修改。空目标不会退回按标签文本匹配文件。外链只保留未访问状态，解析不执行HTML或项目代码。

引用必须完整位于所选范围；截断到一半的链接保持未知。手工选区先定位到原始候选正文，保留围栏等语法上下文，不能把代码示例中的局部字符串当成真实引用。缺少完整AI正文的旧历史只使用原来保存的片段，标记片段外上下文未知；不能借用会话图摘要补齐。CRLF规范化仅用于解析和定位，保存原话不改写，行号保留原来源语义。

每份历史来源最多解析64 KiB，每个比较索引共1 MiB解析输入并按正文指纹复用，最多256个定义／1024个使用位置；比较原有的16引用／片段、512引用／128条／512 KiB输出和1 MiB目标哈希预算保持。无法定位、解析预算或来源不足均明确未知，不宣称无依据。

## 人工主题与片段选择

手工选择也覆盖历史文件节点中已经保存的非Markdown文本，包括TXT、代码和解析文档文本，明确标记“已保存文本”，不自动变为结论。行号只表示保存文本中的行，不承诺PDF页码或原文件物理行；缺失正文、来源不可用、读取失败、重复编号及无效文本不可选并显示部分状态。非Markdown选区不按Markdown语法推断引用，返回 `source_not_markdown` 及未知边界。不能读取当前文件填补历史。

从两次保留的历史观察选择来源，可明确使用整段，或在只读原文中拖选局部文字。同一主题可关联最多32次观察，每次观察保留一个当前选择；重新保存可调整选择，停用保留原标记。不同问题、不同标题或无标题答复只有经过操作者显式关联才按主题并列比较；自动结论比较不被覆盖。来源类型仍保留“AI答复／文档摘录”等原分类，不因人工选定就冒充模型已经作出结论。

选择令牌绑定工作区、知识／代码视图、观察编号／摘要、来源身份和原文。客户端仅提交令牌及选择范围，服务端从历史重建原话，拒绝伪造正文／错误来源／过期观察和切断emoji的偏移。浏览器UTF-16与CRLF换行映射保留原始片段，不按字符猜测范围。候选列表每观察最多128项／256 KiB，正文摘录仍受已保存范围和每片段4 KiB限制；可按节点编号缩小范围。未保存的正文不能回填成历史。

标记存于本机持久数据区 `knowledge/topics/`，工作区和视图分别隔离，采用独立密钥域的AES-GCM信封，目录按需0700、文件0600。它不属于可再生索引缓存，清理索引缓存不删除人工标记；最多32个主题、2 MiB序列化数据，达到限制则拒绝覆盖旧记录。锁定、错误工作区、修订冲突、损坏／未知格式、取消及符号链接守卫保持。取消与提交竞态时须重新读取确认，不谎报保存失败或成功。

历史观察淘汰后，仍可查看操作者当时选定的旧原话，但不能重新核验已失去的完整依据，也不自动对齐到新的观察。缺少双边标记或锚点不匹配均不推断观点撤回。人工主题仅比较选定片段内的明确引用；其他上下文不自动推断为依据。标记随本机数据卷备份，普通配置导出不包含这些原话；本批没有新增跨实例同步或自动密钥迁移。
