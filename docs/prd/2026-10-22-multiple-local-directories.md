# 多个本地目录挂载

状态：实现与隔离验收；不代表生产部署或 Windows 实机验收。

## 用户场景

在设置的“文件与知识 → 本地目录”中维护最多 16 个额外宿主目录，支持 Windows 盘符路径和 macOS 外置盘目录。每项命名并独立选择只读或读写，新增默认只读。宿主原生选择器负责选择电脑目录；路径也可手动输入。目录浏览器可切换已生效目录，选择结果还原为宿主路径。额外目录用于工作区或资料；新增挂载工作区的默认缓存保存在 Aide 内部数据区，额外挂载目录暂不能直接作为缓存位置。

## 生效与恢复

保存写入期望配置，不直接修改 Docker。应用需要页面确认及宿主窗口确认，并只重建 Aide 服务。界面区分待应用与实际挂载；重启后依据只读快照恢复实际状态。拔出的磁盘不创建空目录替代，显示不可用原因。既有工作区、引用或运行会话依赖目录时，应先保存并结束工作。应用失败恢复原配置和容器；恢复失败提示使用启动器。

## 权限边界

宿主 companion 由所选镜像提取并校验 SHA-256，在电脑运行；Aide 容器不持有 Docker socket。接口受既有身份认证和锁屏策略约束，目录配置使用版本比较防止覆盖他人编辑。拒绝整个磁盘、UNC、路径穿越、重复/重叠目录以及与既有宿主绑定重叠的别名，避免只读目录通过其他读写路径绕过。Docker bind mount 同时执行只读限制；只读目录不能作为需写入的工作空间。

## 交付限制

仅 Windows/macOS 提供原生选择及在线应用；其他平台可保存路径并通过启动器应用。Windows ARM64/AMD64 编译与 PowerShell 解析不等于实机验收。原生选择器实际点选、外置磁盘拔插和 Windows Docker Desktop 实机验证应保留为明确待验收项。商业插件不得混入公开宿主包。
