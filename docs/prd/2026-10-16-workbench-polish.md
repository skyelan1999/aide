# 工作台协调与动态背景

用户要求整体打磨图标、边框、尺寸与渲染，支持加载动态背景。

沿用现有工作台结构，统一共用工具按钮、侧栏条目、输入区、正文、文件区和设置面板的尺寸与间距。图标维持现有 SVG 体系，限制为固定视框，避免不同字体图标撑高行。正文维持明确的不透明阅读底色。

外观设置提供关闭、流光、本地素材；默认关闭。流光为纯 CSS 渐变，不使用循环脚本或外部资源。本地素材支持 MP4、WebM、GIF、PNG、JPEG、WebP，最多30 MiB，存在当前浏览器 IndexedDB，不写服务端、不上传、不接入会话附件。刷新恢复，替换仅在存储成功后覆盖；删除可清理素材。

页面隐藏或锁屏时暂停动画与视频；减少动态效果时流光保持静态，动态素材隐藏。视频静音循环、内联播放；播放失败保留可读的普通背景。关闭与切换释放播放器和对象 URL，单页面只保留一个装饰层。背景不接收点击，不参与读屏。界面可读性优先于背景可见度。

本机运行更新沿用 start.command，离线包保留前一版本回滚。生产组件浏览器验收与完整认证 Safari 验收分别记录。
