# 记忆神经：独立 token 图

## 入口与数据

项目文件标题栏中，记忆神经图标位于知识星图左侧。打开 `/memory-neural.html` 独立页面。`GET /api/memory-neural` 使用现有 Bearer 鉴权；配置密码且锁定时返回 423。页面接入 LockCluster，锁定时中止请求、停止绘制并清除已显示的记忆；解锁后重新读取。

数据范围仅为当前项目 Aide 记忆，不扫描项目文件，不读取小秘私有记忆或历史。原有项目缓存选址规则保持有效。SSH 项目页面展示本地项目缓存；`read_memory` / `write_memory` 是远端缓存同步边界，页面轮询不会自动进行 SSH 访问。

## 存储与兼容

`<projectCacheDir>/memory-tokens.json` 保存版本、分词器 ID、token 字典以及有序记忆记录。记录包含 token ID 序列、来源、功能区域和时间。每个不同 token 类型对应一个神经元，多次出现共享此节点；界面分别统计神经元数和 token 出现次数，不把每次出现冒称为一个不同节点。

首版分词器为 `unicode-scalar-v1`，以 Unicode 字符拆分，emoji 单个标量不拆为 UTF-8 字节。它不是 DeepSeek/OpenAI 等模型的 BPE 分词器。`memoryTokenizers` 注册表是版本化 codec 扩展点；增加实现应保留既有 ID 的语义和旧记录，不能直接用新规则重解释旧字典。API 同时返回分词器名称和规则说明，页面从返回值显示，扩展实现不再需要修改页面的分词说明。首版没有用户安装分词器或实时切换模型分词器功能。

`write_memory` 保存 token 记录；`read_memory` 和模型上下文从记录重构文本。`memory.md` 为兼容投影，保持小秘现有只读接口有效。旧文本按行导入，每行内容及换行保留，编号按位置/内容稳定生成，导入时间取原文件修改时间。仅查看兼容快照不创建 token 文件，首次 `write_memory` 才持久化 token 记录。

外部编辑 `memory.md` 导致投影 hash 不一致时，当前文本作为替换快照导入，避免恢复已删除内容或反复追加旧内容。投影缺失时从 JSON 重构；JSON 损坏/未知分词器/字典引用损坏则返回错误，拒绝覆盖。读取不跟随记忆文件符号链接。UTF-8 文本总容量保留 24 KiB 上限。

保存先原子替换文本投影，再原子替换 JSON。两文件不是事务；JSON 保存失败会明确提示文本已保存，下次读取可从文本恢复。SSH 依次同步投影与 JSON，同步失败明确报告本地已保存、远端失败；不能宣称跨服务器原子提交。远端拉取仅增加 `aide/memory-tokens.json` 这一受控文件，不泛化为全部 JSON。

## 可解释关系与视觉

- 神经元：token 类型，显示出现次数、参与记忆数和区域分布。
- 连线：记录内部相邻 token 的有向顺序计数，非语义推断、运行时激活或生物突触测量。
- 共享：同一 token 被多条记录使用；详情列出来源原文。
- 功能区域：偏好、约束、决策、事实、流程、笔记。`keyword-heuristic-v1` 为关键词规则推断，不是模型分类或训练结果；token 可以跨区域参与。
- 图形：胞体、分枝、弯曲连接及选中关系上的流动粒子。位置按区域权重与稳定 ID 布局，保留平移/缩放；每 6 秒读取本地快照，内容变化才更新布局，不重载页面。
- 支持 token / T 编号 / 原文搜索、区域筛选、键盘可操作结果列表与详情关闭、平滑归位和动效开关。减少动态效果偏好生效，隐藏标签页暂停请求与动画。
- 图数据上限：按出现频率显示 1200 个神经元、4800 条连接；普通画面绘制最多约 650 条非选中连接，选中关系仍绘制。总量与截断标志会明确显示，不能把图形数量当作完整模型记忆容量。

这是 Aide 产品的独立记忆组织视图，不代表模型内部权重、隐藏状态、注意力或神经网络结构。

## 验收边界

单测覆盖 token 持久化、共享区域、Unicode、稳定旧记录、兼容投影外部修改/缺失、容量、损坏保护、符号链接、鉴权路由、锁定、工作区隔离及图容量。页面通过本机隔离真实 Aide Handler 使用样例记忆检查。生产 9999 实例未更新。2026-10-09 真实双服务器 SSH/SFTP 回归两轮（race）通过：token JSON 与兼容文本写入工作区服务器上的独立缓存路径，删除测试本地工作副本后 `read_memory` 从远端恢复，`/api/memory-neural` 返回当前工作区及本地工作副本同步标记。此项仅证明 API/缓存链路；浏览器 SSH 操作及真实模型记忆使用仍需后续联调。详见 `../../tasks/ssh-continuity-integration-20261009.json`。
