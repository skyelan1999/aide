# 按需执行环境设计（2026-11-01）

## 大文件收尾与中断恢复

环境收尾先以固定缓冲区流式计算文件摘要；未修改文件不加载到提案内存，也不复制为变更产物。变更文件流式保存到产物目录，再以跨块 UTF-8／无 NUL 校验识别文本；二进制只保留磁盘证据，变更文本仍进入既有完整内容提案流程。这里没有新增文件大小上限；大型文本提案仍需要与内容量相应的内存。流式读取逐块检查取消。

候选合并先对本次所选文件做完整路径、版本和已有提案冲突预检，再逐项通过普通 `write_file` 登记。每个成功登记的路径立即与任务提案一同保存到会话，并更新产物收据，然后才执行可能失败的结果检查点或 after-tool hook。中断返回的 `MergedPaths` 表示实际已登记的成功子集，`Merged` 只在所有候选均登记后为真；两者都不表示文件已应用。重试或恢复执行池只登记剩余路径，保留原有提案、工具审计、预算消耗和审批边界，不自动重放失败 hook。

回归覆盖大文件收尾内存、完整二进制产物摘要、跨块 Unicode、取消、after-tool hook 拒绝、产物收据写入失败、会话持久化与恢复后幂等重试。对应问题：[711](https://github.com/skyelan1999/aide/issues/711)、[712](https://github.com/skyelan1999/aide/issues/712)。

## 调度与兼容

默认采用异步协同：主工具循环用 environment_submit_batch 或 environment_submit 派出独立工作后，继续完成自己的实现、集成准备或有效验证；用 environment_collect_ready 优先收集先完成者，仅在没有其他有用工作时等待。X包含正在工作的主环境和最多X-1个临时环境，例如5X为主环境加最多4个子环境，10X为主环境加最多9个子环境。调度决定分工与占用，不设固定管理角色，不强制占满。1X仍只运行普通主环境，不创建子运行时。

显式声明工具范围的自定义 Agent（AgentToolsSet=true 且 AgentTools 包含 environment_run_queue，且未被权限规则禁用）可选择保留的同步排空实验；普通聊天不披露该工具，旧历史中的同名调用也会返回异步用法提示，不启动工作。同步路径可原子提交并运行一个批次，或排空既有队列；environment_submit 单项异步提交，environment_submit_batch 原子批量异步入队，等待依赖和槽位后才建立临时目录。environment_collect 取回指定任务的真实工具证据并可登记提案，environment_collect_ready 收集先完成者；environment_cancel 中止单个任务；environment_exchange 提供仅限本任务的版本化交换；environment_load_plugin 复制当前项目已启用插件并动态披露工具；environment_shared_tool 将共享设备操作送回主协调器。

大任务可拆成可独立核验的小块，待办数可以多于槽位数。50项是可承载的规模示例，不是固定目标、上限或最低数量。默认异步队列按就绪FIFO取任务；显式同步实验的run_queue随机选取依赖已完成的任务，`order=fifo`可选就绪FIFO。随机只改变就绪项选择，不随机拆分任务或绕过依赖。每次完成并释放私有环境后，执行池直接补下一项，不等待主模型再次派工。排队项只保留元数据，不启动模型、插件进程或源码快照。根据启动/上下文开销与工作量选择粒度，简单或顺序工作继续走普通主环境。

`environment_run_queue({jobs?,order?,merge?})`把任务分发与收集交给代码，不额外启动管理模型。主模型在同步工具执行期间不继续发起自身推理；10X工作阶段可以是10个实际工作环境，默认异步工作阶段为最多9个子环境加正在工作的主模型。取消会关闭并join本任务执行池，全部临时任务结束后才归还借用槽位；无效批次不借槽、不产生部分执行，同一池不允许嵌套run_queue。返回精简状态/候选路径清单与冲突计数，预览最多32项，完整ID可分页查询；不转录每个子任务的全部源码、计划和工具历史。代码收集沿用普通版本/冲突/审批，不自动apply；某项冲突不会无限重试或掩盖其他成功结果，主模型随后按需检查证据、处理冲突与独立验证。

同步队列期间普通对话steering由主模型恢复后处理，停止/取消仍即时传递给队列；需要主模型同时处理交互或其他有用工作时使用异步路径。完整验收与实测限制见[全工作槽位记录](../reviews/2026-11-01/work-queue-all-slots.md)，不将请求并发或槽位占满当作整轮倍速证明。

`environment_submit_batch({jobs:[{key,assignment,dependsOn}]})` 可使用本批次唯一key或既有任务ID引用依赖，也可向后引用。整批检查空任务、重复/歧义key、缺失依赖和环，成功持久化接受记录后才启动；验证失败不启动部分批次。每项返回稳定ID，单项旧接口兼容。依赖仅保证执行先后，**不会自动应用、复制或验收前置候选**；有代码数据依赖的集成仍交主环境或显式交换证据。前置失败/取消则下游失败且不启动，取消排队项不占用槽位，池关闭会取消运行项并结束排队项，不自动重放。

`environment_queue({after,limit})` 提供分页ID、分工参考、依赖、状态、收集/提案状态及全队列计数；limit默认32，只限制显示。运行态精简账本保留全局状态计数、就绪数和依赖阻塞数，显示省略的任务可分页查询。`environment_collect_ready({wait,merge,limit})` 默认每次返回最多8个已完成回执，wait=true可取消地等待任意一项结束，不等指定慢任务。merge逐项沿用普通版本/冲突检查；某项失败不会抹掉其他成功结果，冲突由主环境用指定ID的detail/paths继续处理。完整证据保留，最终仍须收集所有任务，不能把子任务完成或入队当作验收。

多环境主调度每轮从运行态重建精简账本，覆盖旧的账本消息，再纳入上下文预算。它包含任务 ID、运行/收集/汇入状态、候选路径和唯一待审批路径，避免有损摘要遗失已完成分工后重复派工。`completed` 仅表示子环境结束；`mergedAsPending` 仅表示已登记普通提案，均不代表已验收或已应用。账本不转录源码和原始工具输出，路径及任务文字仍是不可信参考；提示预算仅限制显示行数和长度，不限制实际文件或任务规模。1X 与远程/捕获工作区的普通主工具路径不注入该账本。

`environment_collect` 默认返回候选路径、内容哈希、原始版本哈希、字节数、逐文件汇入状态和有限工具证据片段。完整源码、输出与工具历史保留在运行态和证据目录，显式 `detail=true` 才送回主模型；片段截断有标记，不能据此声称完整核验。可用 `merge=true, paths=["src/module.js"]` 只登记明确选定的候选，未指定 paths 时仍对全部剩余候选做整批冲突/版本预检。已登记路径保留在 mergedPaths，重复收集不重复写入提案；整个结果的 merged 仅在全部候选已登记后为 true。选择部分文件不抹掉其他冲突，不自动应用，也不改变普通项目审批策略。

每个临时环境创建独立 App 运行态并复用 toolLoop、executeToolCall、Shell 审批、插件宿主和 daemon 生命周期。它不运行 New 的服务启动、账户迁移、后台巡检或生产连接，不继承全局工作区切换状态。工作区文件工具受 os.Root 约束；Shell 使用现有 Landlock；私有 Node 宿主和守护进程也以 Landlock 运行。它是目录与进程隔离的执行运行时，不是虚拟机；不宣称网络、内核或硬件已虚拟化。

主环境维持普通项目开发能力。受限临时环境禁止递归创建用户子会话和修改全局插件/引用设置；这些工作由主环境承担。可信插件副本具有私有状态；外部资源仍由主协调器与共享队列管理，具备完整工作区/插件私有资源声明的插件可在各环境并行；未知资源声明保守地与主插件队列互斥。未提供物理设备多实例承诺。

快照保留已提交、未提交和未跟踪普通源码；不跟随符号链接、特殊文件，也不复制 .git、.aide-data、.cache、.agent-state、node_modules。省略清单交给工作者，所需依赖由正常流程准备。私有插件按需从主项目启用注册表复制，完整复制插件依赖目录；插件服务依赖需要显式加载。环境内 write_file 经过普通提案校验后写入私有目录，以便随后实测，汇入主项目仍是单独的待审批提案。

环境结果包含身份、分工、状态、输出、实际工具、用量、候选修改、不能自动合并的内容和释放回执。结果与文件保存在服务数据 execution-results/<task>/<environment>/；二进制及删除须由主执行器处理，不盲目拼接。并发候选同路径冲突和主文件变化一律保留候选、拒绝覆盖；正常 apply 再次校验版本。

旧 ParallelProgress 检查点维持原分析兼容路径；新聊天默认使用环境调度，不再强制旧分析波次。先前只读并行工具、上下文压缩恢复、严格草稿校验保留。普通 1X 不增加环境工具 schema；多环境预览与实际首请求共用调度指令和声明，避免挤占小窗口模型的正常开发预算。暂停/恢复已结束结果可继续收集；未完成结果标记 interrupted，不自动重放。
