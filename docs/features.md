## 目录、引用和插件管理

![引用锁与自动系统文档](images/current-20261017/03-references.jpg)

自动系统文档绑定在工作空间配置中，路径可变。正式文档用 `write_file` 的 `source=system-docs` 指向该绑定；用户指定其他引用时使用其来源 ID 和相对路径。普通引用必须同时满足启用、AI 可见和可写。`/context` 默认只读，不能以“自动系统文档”的名称绕过只读挂载。

四阶段建档和 Office 生成在已配置时使用文档绑定；未配置时四阶段工具保留项目缓存 `system-docs/` 的旧路径，正式文件提案不因此自动获得 `/context` 写权限。项目记忆仍归项目缓存。详见[使用指南](user-guide.md)和[模块说明](architecture/modules.md)。

![四项管理权限](images/current-20261017/05-management.jpg)

设置 → AI 管理权限分别控制助理/aide 管理插件与引用，默认均关闭。它们仅控制创建、修改、安装、启停、删除等管理动作，不改变已启用插件调用或引用文件读写规则。插件工坊可按协议信息制作包、检查语法并生成可下载 ZIP；管理变更进入人工确认队列，不能被助理代审自动批准。插件是可信 Node 代码，不是恶意代码沙箱。

## 工作统筹助理与语音

![工作统筹设置](images/current-20261017/06-assistant-settings.jpg)

通过身份验证后，页面内的助理自动跟进交办任务、提醒和授权消息；没有“陪伴启用”总开关。点击麦克风才开始持续收听；切换工作会话继续跟进，隐藏页面停止收听，锁屏或关闭页面停止统筹。空闲交流是补充，工作统筹是主要职责。

助理能创建并启动/排队工作任务，相关消息带助理来源标签。设置中的“允许助理代审交办任务”是独立授权：只能在其范围内审核命令及新文件；现有文件覆盖、身份验证、业务澄清和消息邀请等仍由用户处理。

![百炼 TTS](images/current-20261017/07-qwen-tts.jpg)

语音回复、音色、语速和引擎统一在设置管理。百炼提供地域、兼容模型、音色目录和独立密钥配置；目录不可达时保留内置列表。百炼失败默认保留文字，仅显式勾选后允许浏览器语音回退；“自动”引擎另有本地/联网神经音与浏览器兜底流程。源码包含人声打断与播放代次取消逻辑，但截图不证明声音效果和真实麦克风识别。

## 消息与提醒

![真实提醒分栏](images/current-20261017/10-reminders.jpg)

消息中心包含会话、联系人、传输、提醒。通信配置在主设置 → 消息，复用账户名称，无名称时禁止启用。六位 Crockford Base32 码用于查找，完整公钥指纹用于设备身份；不以 IP 或网卡作为身份，也不能把六位短码当作全球唯一安全凭据。

联系人需对方同意；群组、语音/多人语音、文件各自需要邀请端同意。支持拉黑和分块断点续传。局域网发现与跨互联网自托管引导/中继分开配置；网络端点加密与文件校验的具体边界见[消息架构](architecture/decentralized-messages.md)。不能仅凭“去中心化加密”承诺匿名、无限人数或所有 NAT 下都能通话。

“允许助理读取和管理消息模块”默认关闭，独立于四项管理权限。开启会把授权消息交给当前模型处理；不让助理自动接受联系人、群组、语音和文件邀请。原有提醒保留全局/工作区/已完成筛选。

## 静域工作台背景

设置 → 通用 → 外观 → 工作台背景 → 静域，选择轻量几何光影背景。原有强度调节、本地素材与后台/锁屏/减少动态效果暂停规则保留，旧鲸鱼娘偏好自动迁移。[实现与历史边界](builtin-background.md)。
