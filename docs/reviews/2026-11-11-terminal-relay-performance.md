# Terminal 中继回显优化与本机验收

日期：2026-11-11；跟踪：[Aide #848](https://github.com/skyelan1999/aide/issues/848)。用户反馈为SSH/Telnet打字回显慢。实现仓库为 `aide-pkg-terminal`，基线 `b2487d1`（1.8.0），本机原安装1.7.0，当前安装1.8.1候选。

## 变更与原因

输入确认现在可附带真实增量输出，短输入最多等待32ms，输出一到立即返回，减少往返宿主的额外轮询；长粘贴不等待。界面在派发时取得偏移，对返回的重叠输出去重，保持单飞、有序输入和结果不明不重发。交互轮询采用8/16/32/40ms退避，行号和时间戳栏合并为每动画帧最多一次更新。

另修复串口脚本的500ms缓冲等待：阻塞等首字节后只读已到达字节。已部署远端脚本需另行更新，本机升级不会自动替换远端。没有修改TLS身份认证、权限或Aide宿主代码。

## 实际验证

全部复用当前本地Aide和已有 `aide-aide-1` 容器，没有另开Aide、Docker或独立浏览器测试实例。

| 检查 | 结果与边界 |
| --- | --- |
| 本机实际Workbench准入、插件daemon、Python TLS1.3中继、25ms延迟Telnet目标，8个按键 | 原版回显中位82.45ms、每键3次桥接调用；最终候选40.93ms、每键1次。约50%下降仅适用于该受控夹具，不含浏览器绘制帧时间，不是用户WAN测量 |
| 最终ZIP解包后用包内生产依赖测试 | 70/70通过；含真实OpenSSH/TLS、Telnet、输入回读、会话/日志、网络边界及虚拟串口 |
| 源码套件与最终窗口调整 | 12ms探索窗口时75/75通过；改成最终32ms后相关10/10再次通过，最终ZIP的70项使用32ms |
| 虚拟串口/TLS二进制回显 | 修改前中位500.50ms，修改后0.29ms；消除缓冲人为等待，不代表物理UART线速变化 |
| 当前Aide实际界面 | 显示1.8.1启用；测试会话经TLS重连，连续输入 `zabcdefghijz`，界面和服务端仅出现一次；点击结束后0运行中 |
| 清理和运行状态 | 删除本任务4条测试记录，临时中继和回显进程停止；既有用户数据保留，服务 `status=ok` |

第一次标准本地ZIP升级遇到已安装依赖文件复制的 `resource deadlock avoided`，旧版保持；完整备份后将145个依赖文件以相同字节原子写回，再经标准接口升级成功。安装后关键源码和构建文件逐字节匹配。未重建或重启Aide服务。

## 正式版当前实例复验

用户要求将本机候选替换为正式Release包。通过当前Aide标准ZIP升级接口安装正式1.8.1，摘要为 `fc42c5a33f4ba440340fa25956aeed6c8b5b3b1561f477f8126064b6b1da5bc3`，1,230,048字节；170个包内文件核对一致（manifest核对发行声明，保留安装元数据）。升级前当前工作区0会话，无运行连接，旧安装自动备份保留。

仅复用已有Aide和容器，在本机建立临时SSH/Telnet目标和真实生成的TLS1.3中继。SSH使用实际OpenSSH客户端并验证新测试主机指纹；认证凭据仅为临时测试端生成，不使用用户设备凭据。两个目标均加入25ms回显延迟。最终各8个单字符输入精确返回：

| 协议 | 回显中位数 | 每键桥接调用 | 校验 |
| --- | ---: | ---: | --- |
| SSH经TLS中继 | 38.47ms | 1次 | 8/8字节、顺序一致 |
| Telnet经TLS中继 | 39.88ms | 1次 | 8/8字节、顺序一致 |

这些是当前安装版本经过实际Aide桥接的受控回显耗时，包含目标25ms延迟，不含浏览器绘制时间，也不是用户外网设备测量。初轮SSH中位103.11ms；发现临时SSH服务端未关闭TCP小包合并，改为 `setNoDelay(true)` 后复测得到上表结果。未修改Aide或插件代码。重启夹具的一次启动竞态导致单条测试连接被拒绝，待夹具就绪后重试通过；异常记录已随本任务记录一起清理，不计入成功样本。

实际原生Aide工作台分别输入 `sshofficialfinal` 与 `telnetofficialfinal`，界面和服务端均只出现一次，无丢字、无重复；Telnet回车与正常结束也已验证。复测前一轮的两项界面标记同样通过。共清理仅本任务创建的5条记录，包括启动竞态失败记录；回到0会话，临时中继进程停止、临时凭据及配置目录删除，自建工作台标签关闭。主界面仍显示1.8.1启用。本轮没有新建Aide或Docker实例，没有重新构建宿主，没有再次发布。

本机证据：`.agent-state/terminal-release-local-20261111/` 下的安装、逐键样本、界面标记与清理回执。真实用户WAN、实际SSH服务器和物理串口仍未测试。
