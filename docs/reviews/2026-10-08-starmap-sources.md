## 实现范围

| 来源 | 当前适配 | 明确边界 |
| --- | --- | --- |
| 本地工作区、引用目录、本地／Skill来源 | 普通文件、目录与已有文档提取 | 跳过隐藏／敏感目录、符号链接；Skill不执行 |
| SSH工作区 | 当前服务器配置目录、SFTP列出和读取 | 空路径为账户home；与工作区连接共用 |

| 独立SFTP | 已启用来源各自配置的服务器和目录 | 使用已有凭据保险库和会话生命周期 |
| HTTP／HTTPS | 配置URL单资源及虚拟文件名 | 不递归爬网页、不执行JS；网页检索收到的HTML原文 |
| FTP／FTPS | Unix目录列表／简单名称列表和读取 | 其他列表格式未验证；特殊文件不作为普通文件 |
| SMB | 已配置URL的单资源 | 沿用curl，不增加共享目录递归浏览能力 |
| MCP | 已发现工具说明的虚拟Markdown目录 | 不启动、发现、调用工具，不自动取得工具结果或资料库 |

来源继续通过现有“辅助资料”配置。星图来源筛选和索引证据显示名称、类型、状态、编号、节点数量；空来源、停用或暂不可用来源仍有独立入口。代码／文档命中、AI引用和回填草稿保留出处。来源名称不替代稳定来源编号，同名路径跨来源保持不同节点。

图谱、增量响应新增 `sources[]`；节点新增 `sourceName/sourceType/origin/format`。来源身份使用服务端进程内的加盐指纹，包含配置和凭据变化，响应不公开连接地址或秘密。停用、改配、移除后不接受旧来源引用；进程重启后旧查看页需重新打开。原文片段继续校验实际文件SHA-256和合法定位／偏移。

会话中的裸相对路径只在全图唯一时推断提及关系；明确编号或来源命名路径可跨来源建立关系。文件内部相对链接仍限制在自己的来源。来源元数据差量只更新界面文字，不重建节点布局；节点增改删沿用既有编号合并和镜头保留。

## 读取与查看链路

`knowledge_sources.go` 提供可取消、有限时限和字节预算的共享读取；图谱、原文、RAG、Office检索插件和编号回填共用该适配。只解析源代码／文档，不运行工作区代码。MCP仅返回已保存的工具说明。

HTTP等来源的原始字节查看不再经过UTF-8文本校验。星图的只读文件查看携带来源身份和知识工作区身份，虚拟资源通过实际格式选择现有查看器。HTTP／SMB的XLSX走只读表格通道并保留Office归档检查；没有新增PPTX查看器。只读DOCX入口避免使用缺乏来源身份守卫的批注编辑通道，普通编辑流程保留。

来源读写标记不授权星图写入。新查看通道最多64MiB、15秒，覆盖SSH原始字节；文档检索单文件16MiB。SFTP错误同时检查标准输出／错误，避免exit 0掩盖目录失败。临时下载在子进程设置文件大小限制，结束删除临时文件。

## 范围限制

- 图谱最多800文件、200目录，按启用区域均分；空区域配额暂不转移。来源多时单来源覆盖会缩小，超限标记部分／截断。
- 远端图谱快照约30秒复用；最多3个并行扫描，单来源4秒、批次6秒，受请求总预算约束。单目录输出256KiB／2000项，单来源正文1MiB，图谱文本只保留前8KiB。
- 连接失败可保留上次节点并标明未核实。超过目录预算的祖先缺失时移出其子节点，避免制造孤立层级；不代表远端文件被删除。
- HTTP／SMB二进制资源在节点图中可仅有配置名称，连通性和正文在文档检索时核实。未实现HTTP元数据订阅、递归爬取或持久化索引。
- RAG仍是本地TF-IDF片段排序；没有向量模型、OCR或完整资料库覆盖保证。无扩展名PDF按文件头识别，无扩展名Office不推断格式。
- SFTP路径类型检查与下载不是原子事务，服务器并发改写仍可能影响结果；文件SHA-256和定位校验不能代替服务器侧快照。
- 浏览器、各协议的真实服务器、真实模型质量与性能未验收，不以旧候选的SSH测试或星图截图作为本功能通过证据。
