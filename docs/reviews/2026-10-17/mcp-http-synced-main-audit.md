## 必须保留的边界

- stdio 参数维持离散数组；HTTP 不接受本地程序/参数混用。
- HTTP 明文限本机，远端使用 HTTPS；拒绝 URL 凭据、查询和片段；凭据仅从加密保险库读取。
- 本机流量不经过环境 HTTP 代理、不跟随重定向；Docker 网关虚拟主机兼容仅用于明确本机端点及独立令牌。
- JSON/SSE 响应及请求有上限、超时可取消，初始化/发现/调用均守住来源或凭据变化；发现结果写入使用比较交换保护。
- AI 调用继续要求服务明确声明只读；发现工具数不等于工具已执行或插件已全部可用。
- 表单切换不泄露隐藏令牌，空令牌保留既有保险库条目。应用当前 main 的新版控件和缓存版本，避免旧版覆盖。
