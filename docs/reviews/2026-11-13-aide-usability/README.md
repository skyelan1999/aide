## 已确认并修复的共性问题

- #883：启用状态与按钮含义混淆，工作台统一声称“本地计算”，缺少共同的使用说明；文件型预览从空工作台进入报错。
- #884：验收条件、验收观察和项目知识草稿在父面板重建时丢失。新增项目/会话/目标范围内的页面草稿；新旧版本冲突须明确选择后才能提交。
- #885：未填知识来源被报成 UTF-8/长度问题。新增必填提示、示例、浏览器校验和字段明确的 API 错误。
- #886：窄屏目标输入被挤成细条；修正选择器优先级及英文导航换行。
- 新开发中的影响/工具搜索框按 Enter 不再误提交表单。

## 私有与本地插件

11 个独立身份均检查 manifest、源码身份、README、适用 UI/配置路径和远端 main，并找到现成安装包或使用正常打包脚本生成未发布候选。在隔离 Aide 中，32 个公开包和 11 个私有/本地包共 43 个初始包通过普通安装接口返回 201；签名和原生包检查没有绕过。随后针对当前源码候选的普通升级亦已实际验证。完整逐项身份、文件摘要、源代码本地变更和截图留在本地私有审查记录，不发布到公共仓库。

私有范围另完成打包入口校验修复（18 项测试），以及当前工作台的元数据、浏览器保存和文件读回修复（104 项测试）。实际普通安装/升级、下载后的独立校验及重新打开通过，源码已在对应私有仓库合并。发现远端实现已重构时，关闭了旧版本专用补丁，保留证据后在当前实现修复；没有覆盖新版工作台。未创建新 Release。

原生 CAD 依赖未就绪时实际显示阻塞；不宣称几何操作通过。真实 ROS/硬件、远程设备、云账号、语音提供商、渲染引擎和商业授权验收没有执行。现有签名、许可、写权限和审批没有绕过。
