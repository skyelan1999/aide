## 已确认并修复的共性问题

- #883：启用状态与按钮含义混淆，工作台统一声称“本地计算”，缺少共同的使用说明；文件型预览从空工作台进入报错。
- #884：验收条件、验收观察和项目知识草稿在父面板重建时丢失。新增项目/会话/目标范围内的页面草稿；新旧版本冲突须明确选择后才能提交。
- #885：未填知识来源被报成 UTF-8/长度问题。新增必填提示、示例、浏览器校验和字段明确的 API 错误。
- #886：窄屏目标输入被挤成细条；修正选择器优先级及英文导航换行。
- 新开发中的影响/工具搜索框按 Enter 不再误提交表单。

## 私有与本地插件

11 个独立身份均检查当前 manifest、源码身份、README 和适用 UI/配置路径。5 个现成包在隔离 Aide 中实际安装，其中 3 个工作台实际打开；一个现成包比当前源码低一个版本，明确作为历史包观察，不代替当前源码验收。其余 6 个未核实到当前可安装包，只记源码检查。完整逐项身份、文件摘要、源代码本地变更和截图留在本地私有审查记录，不发布到公共仓库。

原生 CAD 依赖未就绪时实际显示阻塞；不宣称几何操作通过。真实 ROS/硬件、远程设备、云账号、语音提供商、渲染引擎和商业授权验收没有执行。现有签名、许可、写权限和审批没有绕过。
