# aide v0.1.17.5-RC8

## 新增与改进

- 插件工作台允许浏览器 Fullscreen API；配套甘特图可占满整个显示器，隐藏地址栏和标签栏，退出后恢复编辑界面。
- 合并主线的助理语音通话、原生双向语音和后台通话改进，以及 Studio 动效调整。
- 普通运行镜像移除 Go、C/C++ 编译工具链，分别提供 ARM64、AMD64 运行包及可选开发工具包，开发工具支持离线导入。

## 修复

- 修复 sandbox 工作台缺少 fullscreen 权限导致只能在窗口内预览的问题，保持原有不透明来源和沙箱限制。
- 保留近期语音 SDK 回归修复。

## 升级影响

工作区、会话及数据挂载保持原位置。需要 Go/C/C++/npm 编译能力时安装同版本可选开发工具包；助理不会自动把命令转发到工具包。私有插件独立安装，不进入公共源码、镜像和发行包。本次是用户明确要求的即时补丁发布；常规周更策略保持不变。

## 已知问题

9999 已完成 Safari 真正全屏和单次 Esc 退出验收。语音服务仍受所选供应商、模型和账户能力约束；未把协议测试等同于真实手机摄像头验收。公开包的 Windows 启动器使用 PowerShell 回归，不能替代用户 Windows Docker Desktop 实机验收。
