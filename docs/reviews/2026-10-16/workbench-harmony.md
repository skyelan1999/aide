# 工作台协调性补充验收

任务 `workbench-harmony-20261016`，基线 `ed954042351c40535282e3feda08d1f7546af489`。开发位于移动硬盘；继承的知识历史后端修改未覆盖、未暂存。

## 修改与原因

实际组件页发现614px视口下侧栏隐藏，但主区仅190px：`macos.css`后置601～950px规则覆盖了700px移动布局。共享样式现在在700px及以下统一单列，并为两行顶栏保留92px。文件面板浮层沿用相同起点。

统一设置项分隔、字体、图标比例及会话正文标题/段落/代码框/表格间距。文件刷新、新建、关闭与设置关闭从字符改为共享SVG描边，保留原有可访问名称和事件ID。

复用本地背景模块，增加10～50%的强度，默认22%。设置保存与跨标签读取均校验数值；强度修改只更改装饰遮罩，不重新读取素材、不重新创建播放器或Blob URL。

- Node背景生命周期回归、i18n回归、两份JS语法及 `git diff --check` 通过。背景回归增加强度边界/非法值/跨标签规范化及调节保持媒体对象与URL的断言。
- 单一IAB组件页使用真实首页标记、全部产品CSS、真实背景模块与分段设置渲染函数，正文与文件数据为合成内容，无模型调用。
