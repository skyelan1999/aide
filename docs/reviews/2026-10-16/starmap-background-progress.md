# 星图后台续扫与连线性能

任务：[starmap-background-progress-20261016](../../tasks/starmap-background-progress-20261016.json)。用户观察到连线长时间未完成，且需点击激活浏览器才继续搜索和连线。

## 已确认原因与修改

1. 隐藏标签页调用 `stopLive()`，同步准备与调度也拒绝隐藏页面；服务端原先随请求逐批扫描。修改为页面显式请求后台续扫，服务端完成当前有界目录／正文队列并发布每批节点和连线，不依赖页面焦点或动画帧。模式任务去重，串行扫描门控保持；身份变化、关闭、连续错误／停滞和期限结束会退出。
2. 显式引用生成逐份正文遍历全部文件。改为一次构建编号、路径与来源命名路径索引，只查实际引用；保留旧关系顺序、证据行列、歧义规则和边数限制。
3. 后台仍暂停画布，但保留请求与低频同步；回前台立即追平，不再将后台时长叠加到节点出生时间而延迟连线显现。扫描仅新增材料或关系时，进行中的正文搜索继续；已知内容、来源身份、移除、改查和锁屏继续取消旧检索。

## 已执行检查

- 隔离、禁网、容器本地源码 Go race 定向回归通过，88.223 秒。一次初始请求后没有任何后续 HTTP 请求，后台独立完成 170 文件与 169 条明确引用；重复请求去重、工作区／策略变化、应用关闭、原请求取消均通过。相邻渐进、本地／远端、共享快照与失败回退测试通过。
- 引用生成与旧实现逐项等价测试覆盖 24 组混合来源、重名、编码、空格、Unicode、前后缀边界、编号引用及证据位置；原引用回归通过。20,000 文本节点的同机 race 合成用例，旧遍历约 48.12 秒、新索引约 0.875 秒，关系结果一致。这不是实际资料库的端到端耗时承诺。
- 新后台生命周期 VM 回归通过：隐藏状态请求／合并、不取消在途请求、后台间隔下限、回前台追平、出生时间、锁屏和离开保护。已有元数据布局测试增加渐进搜索所有权及首份正文发现断言。

## 进行中与边界

最终源码的 quick/full、真实 Safari 后台观测、运行镜像更新和本批次发布仍待执行，不能据源码或合成用例声称本机已部署。现行发布镜像及原数据保留。浏览器可冻结后台页面，服务端续扫不依赖其继续运行；电脑休眠、Docker 停止或来源不可用时不能承诺扫描持续。
