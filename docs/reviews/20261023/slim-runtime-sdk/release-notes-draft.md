# 精简运行环境与独立开发工具包（发布说明草稿，未发布）

默认运行镜像移除 Go SDK、C/C++ 编译器、make 和 npm/npx，保留 Python、Node、Git/SSH、Office/DXF 与离线语音运行依赖。日常使用和预编译插件继续使用普通运行包；需要编译代码时，可单独安装开发工具包，支持校验后离线导入。

本地同源码 ARM64 全量包由 582.4 MB 降为 359.7 MB，减少 222.8 MB（38.25%）。这是受控本地测试结果，最终双架构正式发布包的大小需构建后另行公布；开发工具包另行下载。

升级影响：直接在普通 Aide 容器中执行 Go/C/C++/npm 编译命令将不再可用，需显式使用开发工具包。助理尚未自动转发这些命令。账户、API Key、会话和工作区数据不需要迁移；数据挂载和启动入口不变，回退仍使用原有镜像/A/B 槽。

发布前必须补入最终版本、实际发布资产、双架构验收和已知问题。这份草稿不代表已合入 main、已发布或已替换现用服务。详细验证边界见同目录 README.md 和 evidence.json。
