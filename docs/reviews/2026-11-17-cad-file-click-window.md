# CAD 文件双击打开窗口

原生 Aide 在连续验收 STEP 文件时，双击文件行会先打开当前页预览，再打开文件标签。两个预览可能同时申请 STEP 解析，触发忙碌提示；重载后可以显示。相同零件按单击逐件打开时未复现忙碌提示。

根因已在文件行真实点击处理器中复现：双击窗口为 450 ms，当前页打开定时器却在 240 ms 触发。第二次点击落在两者之间时，清除定时器已无法撤销首次预览。

`node scripts/file-click-open-window.test.cjs` 使用真实处理器和虚拟时钟，修改前在 250 ms 双击用例失败，实际产生一次当前页打开。修复将单击打开延迟放到整个双击窗口之后；覆盖快速、慢速和边界双击，以及单击、独立点击、修饰键选择和目录导航。
