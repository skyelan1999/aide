# aide 0.1.14.0 RC9

## macOS first launch

The macOS launcher ZIP now explains the Gatekeeper first-run approval steps and a narrowly scoped Terminal fallback for `start.command`. The package is not signed with an Apple Developer ID or notarized; this release does not remove Gatekeeper prompts. Follow the included instructions only after verifying the archive came from the official aide release.

## Release assets

The release should include the macOS Apple Silicon, Windows ARM64, and Ubuntu ARM64 launcher ZIPs, the matching Linux ARM64 container image archive, `SHA256SUMS`, and `RELEASE-ASSETS.txt`.
