# URDF 预览实现与验收

任务：[urdf-preview-20261019](../../tasks/urdf-preview-20261019.json)；使用与范围：[URDF 预览](../../prd/2026-10-19-urdf-preview.md)。基线 main `266079cb`，开发分支 `feat/urdf-preview-20261019`。

## 实现

项目编辑器和独立文件页识别 `.urdf`／备份类型，默认使用三维查看器，仍以原文本接口载入完整 XML、保留草稿、保存权限和历史能力。编辑／预览切换使用现有模式按钮。`urdf-preview.js` 延迟加载离线 vendor，使用原文件 raw API 读取有作用域的 mesh、纹理和 package.xml；没有新增后端接口、ROS 命令或系统依赖。

查看器提供关节限位与 mimic、连杆层级、包目录覆盖、碰撞模型、坐标轴、线框、重置视角和取消。资源读取使用 AbortController 和流式限额，最多 2 个 mesh 任务同时处理；非法树、成环 mimic、异常数字、STL 伪造面数和 DAE 索引数量提前拒绝。关闭／模式变化／锁屏清理下载、DOM、GPU 对象、Blob 与监听器。标准与明确未支持项见 PRD，不把静态 URDF 查看器称为仿真器。

## 浏览器观察

使用公开的合成机器人夹具 `scripts/fixtures/urdf/robot_description/`：6 个连杆、5 个关节、STL／DAE mesh、URDF／DAE 纹理、package.xml 和可替换的 OBJ。PNG 为生成的 4×4 纹理，几何均为自建基础形状，没有真实项目资料。

组件页直接使用真实产品模块，以及从 app.js 提取的实际编辑模式、加载包装和销毁函数；只替代文件服务及外围应用状态，不模拟 WebGL。内置浏览器和原生 Safari 都看到完整机器人、2024 三角面与关节面板。内置浏览器实际将 shoulder 调到 0.8 rad、slide 调到 0.08 m，并观察外形变化；检查碰撞几何、坐标轴、显式包路径重新加载与 OBJ 材质。Safari 确认真实渲染；其 AX 数值写入没有产生可观察的关节变化，不把该动作另外算作 Safari 调节通过。

进一步实测：缺失 STL 时显示“部分资源未加载”和具体问题，其他部件可见；延迟网格显示 1/2 进度，取消后 canvas 数为 0，XML 草稿仍在；切回源码原文长度 2302，画布清除；关闭和锁屏后画布、关节控件清除。画布清除不等同于精确测得浏览器内存回收量，本轮未声称内存下降某个数字。

查看桌面明色与 390×844 暗色窄屏。窄屏 scrollWidth 为 390、查看器宽 356，没有横向溢出，三维区和关节区上下排列。截图在私有 `.agent-state/urdf-preview-20261019/desktop.png`、`narrow.png`、`safari.png`。组件明暗仅影响测试页，不改变用户工作台主题。
