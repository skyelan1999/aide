## Source provenance and ownership

Aide `LICENSE` claims MIT copyright 2026 Skye Lan; `git shortlog --all` shows `skyelan` and `skla` identities plus `lan tian` (15 commits) and `Skye Lan`. Git authorship alone does not establish identity, ownership or assignment. No commission agreements, contributor license grants, employment terms or assignment documents were located in the checked-out source. **The single copyright line does not prove it covers all actual contributors or commissioned work.** Obtain private provenance/assignment evidence before changing that attribution.

The local DeepSeek Harness reference checkout at `../Harness/deepseek-ai--deepseek-harness` is commit `c291e7961a515f6d7af9304e7fd1d257929aef26`, with an [MIT license](https://github.com/deepseek-ai/deepseek-harness/blob/master/LICENSE) naming DeepSeek. Aide's READMEs and architecture docs call it design inspiration, and inspected Aide implementation is Go/vanilla JS while the cited Harness agent loop is TypeScript. If specific code was copied or adapted, its original copyright/permission notice still needs to travel with that code; these observations do not prove no copying.

[CodeStory's archived Aide repository](https://github.com/codestoryai/aide) is a VS Code fork under AGPL-3.0, distinct from this Go-based Aide project. `rg` found no `CodeStory`/`codestory` reference in the checked-out app/docs outside this audit, and the current Git remote points to `skyelan1999/aide`. This is a **limited provenance screen**, not a complete similarity analysis of the huge CodeStory tree; no AGPL reuse has been established, and absence cannot be certified from name/path search alone. Preserve a record of any imported snippets if identified later.

An independent exact-file check used the [official CodeStory Git tree](https://api.github.com/repos/codestoryai/aide/git/trees/93c820fbc9d14b42047b658518677df66f1ef644?recursive=1) at default-branch commit `93c820fbc9d14b42047b658518677df66f1ef644`.
