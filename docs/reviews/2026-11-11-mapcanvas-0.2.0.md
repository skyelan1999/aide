# MapCanvas 0.2.0：路径收起、灰色画笔和 AI 工具

任务mapcanvas-ai-tools-20261111；集中Issue [#843](https://github.com/skyelan1999/aide/issues/843)。宿主基线0966e0a0，公用插件基线fb457bd。当前本地实例沿用localhost:9999和aide-aide-1，无第二个生产Aide服务或新测试容器。

## 功能与接口

浏览/上级右侧新增路径列表显示/隐藏按钮，保留目录与结果，导入后自动收起。灰色画笔按YAML的free/occupied阈值和negate选择可表达的未知灰度，支持16位PGM，与撤销/重做和原图保存共用既有通道。

新增mapcanvas_help、mapcanvas_preview、mapcanvas_edit。预览返回受限PNG视觉证据、原图坐标映射和图像/YAML摘要，可裁剪或只读试画；编辑校验两项摘要，按像素笔画/矩形导出PGM+配套YAML文件提案，沿用宿主应用流程。插件内置AI-GUIDE.md及界面指南入口，描述坐标、试画、提案和读回复核。工具与浏览器共用同一地图核心；主程序无需新增执行权限或运行时接口。
