# 用户语音主动挂断 SIP 电话

用户确认，本轮重点是“小绵不能主动挂断”。上一通实际电话中，用户说“挂了吧，挂了吧，你给挂了吧”，助理只说告别语；网关没有主动挂断事件，最终是话机发送 SIP BYE。本次只修电话结束动作，未将其他回答质量问题扩大到本任务，也未修改已有待审事项。

## 实现

宿主根据当前完整转写识别明确挂断要求或简短道别，不使用历史、模型生成文本或任意工具参数作为挂断授权。完整句白名单拒绝否定、引用、假设、延后要求、停止任务和过期轮次。新的有效发言在执行前可以撤回待执行挂断。仅普通 SIP 通话使用此控制，不改变任务审批权限。

宿主发送 `aide.call_end`；网关等待关联告别响应完成、播放队列排空及 250 毫秒音频尾部间隔，最长六秒，再关闭语音 socket 并发送 SIP BYE。宿主另有八秒回退。没有增加模型或 TTS 请求。取消的是未完成的 helper，已正式交办任务仍沿既有独立生命周期运行。

原来的 `gateway.ended` 同时表示 WebSocket 结束和话机挂断，用它决定是否发送 BYE 会漏掉“语音连接先关闭”的主动结束路径。现以 `peer_ended` 记录真正来自话机的 BYE／CANCEL，`bye_sent` 保证主动 BYE 只发送一次。正常回拨报告仍沿既有自动结束路径。

## 实际验证

- 22 项聚焦 Go 顶层测试在 race detector 下通过，包括意图边界、迟到转写、撤回、宿主回退、服务商伪造控制事件不透传、宿主动作及已付费 provider socket 关闭、原有实时语音与回拨回归。
- 15 项 Python 电话脚本测试通过，包括匹配告别响应、排空、晚到转写、超时、撤回，以及 WebSocket 先结束后仍真正发送一次 SIP BYE 的回归。
- 文档检查、`git diff --check` 通过；最终本地构建、`go vet`、安装与服务启动结果见私有证据目录。
- 原 35 项待审身份及其所在 24 个会话文件哈希保护仍执行，未据此批准、恢复或修改任务。

最终修订版本已完成真实话机验收：用户明确反馈“已经自动挂断”。网关记录宿主挂断请求、告别响应完成、主动结束、SIP BYE 成功回执，识别挂断请求到回执耗时 2.724 秒；没有发起任何 native helper 工具调用。服务端记录客户端正常 hangup，网关回到 waiting。35 项待审与24个受保护会话文件均未变化。未推送或公开发布。
