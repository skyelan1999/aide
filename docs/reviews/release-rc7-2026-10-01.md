# aide 0.1.14.0 RC7 发布记录

日期：2026-10-01

GitHub 预发布：[aide 0.1.14.0 RC7](https://github.com/skyelan1999/aide/releases/tag/v0.1.14.0-RC7) · tag `v0.1.14.0-RC7` · 发布提交 `df411b7ba1bbff29395258bc92daec2ba0069806`。

## 范围

RC6 后的更新包括：

- 设置中可修改离线启动包绑定端口；监视器自动重建服务，当前标签页等待新服务就绪后替换到新地址。启动脚本默认使用 8097，端口被占用时自动选择并记忆可用端口。
- 虚拟形象设置与导入素材同步保存在工作区数据卷，同一工作区切换 localhost 端口后读取同一配置。
- 设置项统一称为“语音助理”，默认名称“小秘”；助理入口、会话标题和锁屏标题读取同一自定义名称。性格设置称为“助理性格系统”。
- 内置素材包改名为“小鲸鱼 - 光栅版 - 原画动态包”，保留稳定 ID 并迁移旧显示名。

## 验证与发布

快速与完整发布门禁通过；候选 Linux ARM64 镜像和三种平台启动包已生成，六个 Release 附件已上传，SHA256SUMS 校验通过。候选镜像临时容器 health=ok、integrity=ok，鉴权 API 可用。端口修改后的真实浏览器同页跳转因执行环境 Mac locked 而 NOT RUN；没有替换当前用户服务。版本、提交/tag、镜像身份、附件校验和部署状态详见[发布任务账本](../tasks/release-2026-10-01-rc7.json)。
