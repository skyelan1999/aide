# aide 0.1.14.0 RC7 发布记录

日期：2026-10-01

## 范围

RC6 后的更新包括：

- 设置中可修改离线启动包绑定端口；监视器自动重建服务，当前标签页等待新服务就绪后替换到新地址。启动脚本默认使用 8097，端口被占用时自动选择并记忆可用端口。
- 虚拟形象设置与导入素材同步保存在工作区数据卷，同一工作区切换 localhost 端口后读取同一配置。
- 设置项统一称为“语音助理”，默认名称“小秘”；助理入口、会话标题和锁屏标题读取同一自定义名称。性格设置称为“助理性格系统”。
- 内置素材包改名为“小鲸鱼 - 光栅版 - 原画动态包”，保留稳定 ID 并迁移旧显示名。

## 验证与发布

发布状态、提交与 tag、镜像身份、资产校验、远程上传、浏览器验收限制和部署状态以[发布任务账本](../tasks/release-2026-10-01-rc7.json)的最终证据为准。未经记录为 PASS 的端到端行为不视为已验证。

## 回滚

代码回到上一已发布 RC6 tag；离线包使用对应 RC6 镜像及平台启动包。不要删除或覆盖现有 Docker 数据卷中的配置、会话、工作区或访问令牌。
