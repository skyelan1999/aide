实现：默认关闭、独立保存的回拨开关；网关私有密钥及一次性源通话票据；仅本次电话新建的任务/run 可以登记。原通话挂断并经过短暂宽限、任务实际完成且没有待审批/待交付后才拨原话机。持久化领取状态后发起单次拨号，漏接/忙线/失败不自动重拨。工作区、话机、解锁、禁用工具和任务状态均重新核对。

回电在话机接听后才连接实时模型，读取当时的实际任务结果。没有任务及审批工具，也有宿主执行拒绝保护；语音发送回执不等于用户已听清。关闭设置取消回拨，不取消原任务。用户指南及设置说明已更新。

实机排查发现并修正两处阻碍：错误的容器启动挂载使工作区退回代码仓库；旧网关进程遗留占用 SIP 端口。恢复标准启动及原工作区，并清理已核实归属的旧进程。电话的千问连接采用声学 VAD，压低音量并经过 G.711 转换的测试语音已取得转写和音频。另一已配置语音提供商返回额度不足，不循环重试。

真实模型只读查询取得 `assistant_work / approval_query / readOnly=true / sessionNumber=188 / pendingCount=0` 宿主回执，查询不创建执行会话。原有 35 项待审仍需在最终验收后再次核对。

文件交办回拨实测暴露的意图错误已由离线测试复现：`不动待审任务` 没被识别为否定保护约束，误触发审批查询工具过滤。修正否定识别，并为“文件工作完成后回电”只提供实际交办工具；没有启动回执不得把回拨管理当成交办成功。回拨管理工具在已有本次任务后才可见。

测试和本地构建、实际回电及听感的最终结果见任务 JSON 和私有 `.agent-state/sip-task-callback-20261122/` 证据；未完成的实机项目不得由模拟或单元测试替代。
