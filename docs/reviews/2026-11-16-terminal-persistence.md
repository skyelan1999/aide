# Terminal 会话持久化修复（2026-11-16）

任务：[terminal-persistence-20261116](../tasks/terminal-persistence-20261116.json)。实现位于 Aide 宿主，适配现有 Terminal 1.8.1，无须修改插件界面或安装包。

## 现象与定位

旧宿主以 `wsID + mode + port + username + storageRoot` 的哈希选择私有会话目录。`storageRoot` 是运行环境映射路径，同一配置工作区在原生路径、容器 `/local` 或其他挂载之间变化时会选择另一个目录；本地模式残留的 SSH 端口和用户名也会改变目录，表现为既有会话、配置和日志不见了。实际输出与配置原先已由插件持久化，重启支持恢复。

当前实例只读盘点确认 `/data` 使用持久 bind mount，现存记录属于两个不同的真实工作区。这不能证明编译删除了数据；不同工作区的记录仍按现有边界隔离。

## 最终行为

宿主按稳定的配置工作区身份保存私有存储定位索引；本地模式不再把临时映射路径、SSH 端口与用户名纳入身份。SSH 仍按主机、端口、用户与目录隔离。首次使用优先认领旧的精确目录，并兼容同一绝对宿主路径的原生和 `/local` 映射；之后始终使用已保存的定位。

索引只保存私有目录哈希，采用原子写入。旧目录原地复用，不移动、复制或删除会话、日志、known_hosts 和中继私有配置。多个真实工作区不合并。非法索引或符号链接返回错误。重启只恢复配置和历史，不自动建立连接或重放命令。

实际验证命令与结果记录在任务 JSON；原始 Go 输出在 `.agent-state/terminal-persistence-20261116/go-tests.log`。新增测试覆盖映射变化、旧目录兼容、身份隔离、并发首访、非法索引及真实 PTY/新 daemon 恢复。

当前 Aide 有用户其他任务和终端，未重启服务或替换运行二进制。当前运行实例尚未加载此宿主修复；源码修复、隔离测试与实例应用状态分别记录。本任务仅合入源码，不发布安装包或市场更新；源码集成结果见关联 PR。

回滚：只撤回本任务宿主源码改动并重新构建。既有目录保持原样，旧版本忽略新增 `.root.json` 定位文件。旧版再次改变映射时仍受旧目录身份问题影响；不得清理用户数据目录。
