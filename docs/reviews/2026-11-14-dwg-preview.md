# DWG 预览验收记录（#899）

本记录区分源码、隔离测试、运行实例与发行状态；Aide 无新版本号、标签或 Release。用户会话、审批、草稿、设置及安装插件必须保留。

## 已验证

- 固定 GNU LibreDWG 0.14 源码、独立 CLI 及对应源码/许可/构建脚本打包；隔离 Docker stage 实际编译成功。
- `TestDWGPreview*`：只读、来源停用及转换中身份失效、路径/符号链接/FIFO、输入输出上限、取消、繁忙和未认证访问、组件缺失和损坏结果。真实 2000/Arc 与 2018/Line 不以模拟器代替；检查 ENTITIES 节中的 ARC/LINE。
- Chromium 1440×1000 中文：从实际项目文件入口打开真实 DWG；弧线、54 实体复杂图纸及新版 LINE 显示。放大、缩小、滚轮、拖动、适应窗口恢复、关闭/重开通过；原文件下载 SHA-256 与输入一致。
- WebKit 390×844 英文：实际文件入口、图形与说明/控件可见，无页面异常；截图发现下载标签缺少翻译，已补齐。
- 错误 DWG 显示文件检查建议、重试及原文件下载。沿用的 DXF 实体/块循环、层深、节点和几何预算回归通过。
- 发现跨版本强制导出会静默丢失几何，已改为保留源版本；2000 和 2018 两端分别验证，不以 CLI 退出码或 HEADER 字符串冒充图形验收。
- quick 门禁通过；Go 全套首轮使用 5 分钟的包级累计限时，在执行既有 Harness 用例时超时，未计为全套通过；15 分钟的第二轮也达到包级累计上限，在执行既有 Reminder 用例时中止，两轮均没有记录为全套通过。专项真实转换、quick 与 CI 关键 Go 门禁分别核对。
