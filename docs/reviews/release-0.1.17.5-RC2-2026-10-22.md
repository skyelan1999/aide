# aide 0.1.17.5 RC2

插件自动安装开关移至「设置 → AI 与权限 → AI 管理权限 → 插件路由」。市场页保留搜索、分类与按需求匹配，沿用现有实例策略和权限规则。

本版包含已合入的插件手机采集桥接、现场照片凭证、多设备区域授权、直接工作区保存与导出交接修复。

Compare、ProfessionalProject 等私有插件独立交付，不随公开源码、镜像或启动包提供；用户项目、会话、令牌和已安装插件也不进入发行附件。市场商业筹备条目不提供安装包。

交付 Linux ARM64、AMD64 完整运行与升级包。实际验证、镜像身份、归档摘要和架构边界记录在 RELEASE-ASSETS.txt；ARM64、AMD64 均执行原生构建和 Go 测试；本地另有全量发布检查与编译界面验收。本次发布不替换用户现用容器，不迁移数据。回退可使用 v0.1.17.4-RC2 和保留的数据卷。

RC1 候选在 AMD64 原生测试中发现升级链接测试样例硬编码 ARM64；RC2 仅修正样例适配当前原生架构，保留已推送的 RC1 标签。应用筛选逻辑未因此放宽。

发布源码：`133fccb84f1fdf013fd89a6a1e9169051f16ae45`。运行源码 SHA-256：`b1e317530cd2d3254b30e9c36169e0757b3700de7111b062adf955d0d913119f`。

验收结果：本地 145 项完整发布检查通过；1,109 个后端顶层用例分 12 组执行 race 检查，另含其他 Go 包与 vet。ARM64 和 AMD64 均在原生 GitHub 节点完成 Go 测试、运行资源、认证烟测、嵌入资源摘要、全部镜像层审计、ZIP CRC/SHA 与镜像导入。
