# aide 0.1.14.0 RC11

RC11 是 RC10 的升级测试目标，软件升级界面会把应用包暂存到非活动槽，供用户手动激活。激活流程由宿主启动器代理执行，并复用原会话、配置和工作区数据。

此 Release 同时提供完整平台启动包和 Linux ARM64 应用内升级 ZIP。新安装请使用 macOS / Windows / Ubuntu 启动器 ZIP；从 RC10 测试升级时，只选择名称带 `-update-` 的应用内升级 ZIP，或选择其解压文件夹。RC9 没有升级界面，应先使用 RC10 启动器安装。

RC11 的应用代码与 RC10 相同，本版更新版本身份用于验证版本比较、包校验、非活动槽暂存和手动激活路径。RC10 全量 Go 测试已通过；RC11 构建重新执行 `go vet` 和容器健康检查。

macOS 启动器未使用 Apple Developer ID 签名，也未公证；首次打开可能出现 Gatekeeper 提示。包内 README 提供首次启动步骤。请只对从官方 Release 下载并校验过的包执行这些步骤。
