# SFTP 下载脚本中继验收（#655）

用户确认：脚本部署在能访问 SFTP 服务的远程设备上，Aide 经脚本访问原 SFTP，保留用户名、密码/私钥及 SSH 主机校验。基线 main `7a1e4b6766fe5f32cdaf5c14204738679218d9fc`，实现分支 `feat/sftp-reference-relay`，[PR #656](https://github.com/skyelan1999/aide/pull/656)。当前仅候选实现与隔离验收；用户的 `localhost:9999` 原安装未升级，未执行合并、tag 或发行。

## 实现

SFTP 类型新增直接/脚本中继选择；中继主机和端口与目标 SFTP 地址分别保存。脚本离线下载，固定转发到单个目标，不包含 SFTP 密码或 SSH 私钥。独立中继密钥与原凭据合并密封，部分更新、锁定、损坏载荷保护均保留。OpenSSH 的目标名称、首次记录/后续拒绝变更的主机密钥策略及认证流程继续使用；经私有临时 ProxyCommand 接入固定身份的 TLS 1.3/挑战中继。配置或凭据变更会退休旧 SSH 主连接。

默认只读，写入继续受 Aide 来源锁、AI 可见性/审批及 SFTP 账户权限控制。SFTP 中继脚本传输的是 SSH 协议，不另外执行本地文件系统写权限判断。部署步骤和 API 见 [远程中继说明](../reference-relay.md)。
