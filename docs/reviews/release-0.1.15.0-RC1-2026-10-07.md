# aide 0.1.15.0 RC1

## 更新

- 自动 AI 工作流采用连续模型工具循环，由模型维护计划、选择下一步、根据真实工具结果调整；保留手动阶段和旧暂停任务兼容。
- 增加 update_plan、工具结果编号和一次收尾自检，计划随任务保存；计划完成不等于操作成功或授权。
- 复用已给出的用户授权，常规研究无需反复询问；真正阻塞的输入通过带选项的询问框收集。
- 集成浏览器与电脑控制插件、网站/应用范围设置、插件 ZIP 包及工作区设置；读网页/PDF 和电脑操作仍受现有权限控制。
- 补齐控制桥接发布资源及依赖清单，统一插件来源指纹。Python PDF 工具支持加密文档依赖。

## 验收依据

新增模型计划校验、入口兼容、HTTP 工具反馈、自检次数、保存/恢复回归；实际 deepseek-chat 在 Safari 完成只读目录任务（3次工具调用、无询问/写入）。详见[验收记录](2026-10-07-model-led-acceptance.md)及[架构说明](../architecture/model-led-agent.md)。最终完整 race/vet 和发行镜像结果由任务记录补充。

## 局限

没有更换用户模型或接入 Codex/Claude 账号。模型在验收中把两步计划拆为3项；一次自检不能保证判断正确。未完成跨模型质量对比、全部主题/窄屏组合、新设备首装及 Windows/Ubuntu 物理启动验证。macOS 控制桥接仍需用户给予系统权限，浏览器 runtime 需按说明安装。发行包不包含本地权限、令牌、会话或用户文件。
