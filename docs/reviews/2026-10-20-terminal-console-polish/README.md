# 设备终端控制台布局 · 2026-10-20

此次迭代把连接导航、终端操作和连接详情分开：

- 左侧按本地环境、SSH设备、历史会话分组，状态用文字表示；名称/主机搜索与筛选保留。
- 中部标签只显示运行中、启动中或当前选中的历史会话，避免历史记录挤占标签栏。
- 1280px及以上显示连接详情，包含当前真实状态、类型、目标、起始目录、创建时间与日志开关。小屏收起详情，连接操作保持可用。
- 独立标签页的宿主工作台铺满窗口，外层标题栏压缩到36px；普通弹层保持原有打开方式。插件主标题和连接工具栏同步收紧。
