# Aide 0.1.17.3 RC1

插件卡片和内嵌工作台增加“在新标签页打开”。独立标签页沿用普通 Aide 鉴权，为当前工作区建立新的隔离工具连接，保留报告保存入口；启动 URL 只包含插件 ID。刷新和关闭页面会释放旧连接。配套 Compare 0.3.1 采用更紧凑的设置区和更大的结果区。

包含上次发行标签之后的本地 PDF 路由修复：本地文档比较不再因 PDF 关键词误入网页研究。

实际 Safari 已验证独立标签页打开、刷新重连、旧连接 403、文本/图片/DOCX 比较和可复核 HTML 下载。图片样例为 23,752 个差异像素、4.723%。具体范围见[工作台验收](2026-10-20-compare-workbench-tabs.md)。未做原生移动设备和完整主题矩阵验收；不将桌面样例外推为这些平台通过。

发布门禁、ARM64/AMD64 构建及镜像健康/鉴权/内嵌源码身份检查在发布记录与附件元数据中单独记录。AMD64 在本机仿真运行，不替代原生 AMD64 硬件验收。沿用现有 Dockerfile.local 本地依赖流程：完整 race 门禁单独通过后，构建层执行语法、vet、build，不重复运行全量门禁。两个 Docker 架构各提供一个完整 ZIP，用于离线新装和 A/B 升级；另附同标签源码 ZIP。

[Compare 0.3.1 私有发行版](https://github.com/skyelan1999/aide-pkg-Compare/releases/tag/v0.3.1)需仓库访问权限。本次不改变商业授权、市场公开范围或比较引擎与证据材料包的技术边界。

发布不自动切换用户正在运行的容器；本机会话、工作区、设置和已验证候选运行环境继续保留。需要回退时使用上一发行包或已有更新槽，不删除数据。

公开包范围已核对：源码 ZIP 的插件文件与公开 Git 标签一致；两个发行镜像的现有文件及全部引用历史层只含公开内置插件，未混入私有插件或本机升级备份。私有插件保持独立私有分发。
