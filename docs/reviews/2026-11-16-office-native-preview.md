# Office layout and presentation preview

The user requests complete XLSX merged-cell/style/image/multiline rendering, native PPT/PPTX page previews, comprehensive verification, and main merge/push. The baseline is `f3cceb37`; pre-existing local work remains outside this isolated worktree.

## Implementation

XLSX now opens in a layout viewer, retaining the source formatting and drawings through a local LibreOffice conversion of a private copy. A private ODS layout roundtrip materializes text that direct OOXML-to-PDF export omitted in one original workbook; all 23 original worksheets are rechecked after this recovery. The [documented PDF export parameters](https://help.libreoffice.org/latest/en-US/text/shared/guide/pdf_params.html) include `SinglePageSheets`, which exports every complete worksheet regardless of print ranges. A post-pass excludes hidden worksheets while retaining visible empty sheets. A worksheet selector maps the resulting pages and fits each selected sheet width. LibreOffice UNO recalculates automatic row heights in the private model; merged anchors are measured in a disposable sheet so continuation fills and borders remain intact. Explicit source heights are preserved. Newline cell edits retain wrap alignment. Cell saving patches the affected worksheet/style/calculation XML parts, rather than rebuilding the workbook with a library that drops legacy images. The original problematic workbook retains all 479 media parts and ten drawing parts byte-for-byte after a private edit test. Shared-formula groups are expanded before changing their anchor; array-formula ranges and merged continuations are rejected without a partial save. The existing cell editor remains available as a separate mode and now preserves literal line breaks with textareas. Switching modes preserves pending cell changes; saving refreshes the content-addressed layout result. Rooted local/mount cell views remain read-only and use the selected root.

PPT and PPTX open in the same bounded page viewer in both modal and standalone file paths. Static slide pages include text, images, tables and shapes. The PDF viewer continues to provide lazy page rendering, navigation, zoom, Fit, teardown and local raster compatibility. Document colors are retained while surrounding controls follow the active theme. Animation and multimedia playback are outside this static page preview.

The new authenticated Office endpoint reuses bounded source reads and checks source identity before and after conversion and cache hits. Conversion has two slots, a deadline, process-group cancellation, bounded input/output and child resource limits. Each request uses a private LibreOffice profile with macros disabled; Linux descendants can create Unix sockets but cannot create network sockets. A four-entry content cache includes the local font profile metadata in its key. No original documents, installed profiles or user-selected shell commands are passed to the converter. Runtime dependencies are installed only at build time, including metric-compatible open fonts and package license notices. Private local fonts remain outside Git and public images.

## Boundaries

The viewer provides static slide/page previews; animations, videos and editable PowerPoint authoring are not included. Whole-sheet XLSX pages can require zooming and scrolling; canvas and file limits remain. Exact Office typography depends on locally available fonts, with bundled metric-compatible fonts used when an original face is unavailable. Explicit source row heights, narrow-column number overflow and intentional blank sheets are retained. Source documents are never rewritten during preview. Only an explicit version-guarded cell save changes a workbook.

The requested delivery is merge/push to main. No tag, GitHub Release, release asset upload, version change or branch-protection change is requested or performed.
