# 工作台外观与背景

设置 → 通用 → 外观提供配色、明暗主题与工作台背景；快捷键在对应设置页配置。

| 配置 | 当前源码选项 |
| --- | --- |
| 配色 | 现代、专业、舒适、经典；内部值为 `modern`、`professional`、`comfort`、`green` |
| 背景 | 关闭、流光、静域、现代光场、护眼、本地素材；内部值为 `off`、`aurora`、`studio`、`modern`、`eye-comfort`、`local` |
| 背景遮罩强度 | 10–50 的整数，默认 22；与动效强度是不同设置 |
| 动态效果 | 跟随系统 `prefers-reduced-motion`，不再提供旧手动动态强度档位 |

静域使用轻量几何光影，随主题配色调整，不依赖原鲸鱼娘 MP4。旧 `whale` 偏好迁移到 `studio`；本地素材另行保留。页面后台、锁屏和减少动态效果的暂停处理用于降低持续动画影响，实际呈现取决于浏览器环境。

选择「护眼」后，低对比度的柔光会缓慢移动，并随明暗主题和背景强度调整。切换到后台、锁屏或主动休息时暂停，系统启用减少动态效果时使用静态柔光。

「每 20 分钟提醒远眺」可以关闭，计时只累计本标签页可见且未锁屏的时间。提醒可以延后 5 分钟。「现在休息」会暂停背景 20 秒，并提示放松视线、看向约 6 米外。切换到其他背景会结束本次计时，背景与提醒偏好保存在当前浏览器。远眺提示参考[美国眼科学会关于屏幕用眼疲劳的建议](https://www.aao.org/eye-health/tips-prevention/what-is-eye-strain)。

源码入口为 `internal/server/web/settings-init.js`、设置 schema 和对应样式。历史素材截图保留在 `docs/images/builtin-whale-20261017/`，只作当时证据，不是可用选项或本轮视觉验收。
