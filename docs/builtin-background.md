# 静域工作台背景

设置 → 通用 → 外观 → 工作台背景 → **静域**。使用低饱和光影、几何切面与细线，随配色及明暗主题自适应；支持背景强度调节。没有视频文件、外部素材请求或逐帧 JavaScript 循环。

默认背景偏好保持不变。旧的 `whale` 偏好迁移到 `studio`；本地上传素材继续保留。“删除本地素材”只删除浏览器上传文件，不影响静域。后台、锁屏及减少动态效果时停止动画。

2026-10-23 移除了原“鲸鱼娘”背景选项与内置 MP4。历史截图和素材来源记录仍保留于 `docs/images/builtin-whale-20261017/`，仅作历史证据，不代表当前可用选项；虚拟形象素材属于另一项功能，本次不修改。
