# 工作台外观与背景

核对日期：2026-11-11；源码 `921a95a5`。设置 → 通用 → 外观提供配色、明暗主题与工作台背景；快捷键在对应设置页配置。

| 配置 | 当前源码选项 |
| --- | --- |
| 配色 | 现代、专业、舒适、经典；内部值为 `modern`、`professional`、`comfort`、`green` |
| 背景 | 关闭、流光、静域、现代、本地素材；内部值为 `off`、`aurora`、`studio`、`modern`、`local` |
| 背景遮罩强度 | 10–50 的整数，默认 22；与动效强度是不同设置 |
| 动态效果 | 跟随系统 `prefers-reduced-motion`，不再提供旧手动动态强度档位 |

静域使用轻量几何光影，随主题配色调整，不依赖原鲸鱼娘 MP4。旧 `whale` 偏好迁移到 `studio`；本地素材另行保留。页面后台、锁屏和减少动态效果的暂停处理用于降低持续动画影响，实际呈现取决于浏览器环境。

源码入口为 `internal/server/web/settings-init.js`、设置 schema 和对应样式。历史素材截图保留在 `docs/images/builtin-whale-20261017/`，只作当时证据，不是可用选项或本轮视觉验收。
