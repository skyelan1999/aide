# 原生实时语音通话

助理页面「语音通话」使用 Qwen3.8 Omni Flash Realtime 的原生音频会话。浏览器连续采集麦克风，AudioWorklet 转为 16 kHz 单声道 PCM，经同源 WebSocket 送入 Aide，再由服务端转发给千问；返回的 24 kHz PCM 增量直接排队播放。此入口不使用浏览器语音识别，也不调用单独的 TTS 合成服务。

## 使用

1. 使用 HTTPS 或 localhost，在助理页面解锁后点击「语音通话」。
2. 允许麦克风；面板显示「原生实时通话」。模型为 `qwen3.8-omni-flash-realtime`，原生音色为 `Tina`，独立于普通朗读与 TTS Tools。
3. 可以边听边说；服务端 semantic VAD 判断轮次，开始说话时清除未播音频并取消旧响应。音频截断按已播放位置提交；旧响应迟到的音频不进入新一轮。
4. 静音释放输入设备，仍可听回复。挂断、离开助理、后台、锁屏或工作区变化结束通话并关闭上游。挂断不会撤销已经启动的后台工作。

千问提供商必须填写业务空间 HTTPS 地址及对应地域 Key。Aide 使用现有密钥保险库解析凭据；Key 不交给浏览器。浏览器仅连接 Aide 同源 WebSocket，以子协议头携带现有本机访问令牌，不把令牌放入 URL。模型服务不可用时明确报错，不静默降级为旧的分轮通话。

## 工作交办与边界

实时模型通过 `assistant_work` 进入现有助理权限链；输入只能使用服务端收到的当前用户转写，浏览器不能注入系统指令、工具结果或任意会话消息。当前轮只处理一次，工具调用 ID 去重。助理仍执行原有权限和审批要求；模型没有独立的文件、终端或消息权限。

转写文字保存到已解锁的助理会话，原始麦克风 PCM 不落盘。每个助理会话同时只允许一通原生通话；单次最长30分钟，无自动付费重连。网络或播放队列明显积压时结束通话，避免不断累积声音。后台工作列表继续更新，通话期间不插播普通任务通知。

云端原生音频按服务商规则计费。原生音频用量暂不并入现有文本 Token 费用图；普通文本单价不能作为音频的准确费用；以千问控制台音频账单为准。下载 MP3/WAV 仍由 TTS Tools 提供，普通朗读偏好保持独立。

## 验证

- Go 模拟上游验证认证、音频双向转发、锁屏关闭连接。
- JavaScript 验证PCM重采样、流式播放、打断、旧音频丢弃、静音释放、迟到权限和网络积压。
- 已以合成语音回灌真实千问服务，确认输入转写、semantic VAD 自动接话和原生 PCM 返回。
- 真人麦克风、扬声器回声和 Safari 主观听感仍需设备体验，不能由合成测试替代。
