# 助理语音通话

助理页面输入框上方提供「语音通话」。用户主动点击后，使用当前浏览器语音识别、助理模型和已配置的回复音色进行连续听说。识别结果仍经过助理原有权限和工具调用路径；它是 ASR → 助理 → TTS 的分轮通话，不是新增原生音频 WebSocket 服务。响应延迟取决于浏览器、模型和 TTS 服务。

- 面板显示连接、聆听、思考、回复状态及本次时长。
- 通话默认一两句口语回复，不列标题或长清单；说话未结束时延长等候，完整句较快提交，浏览器识别重连不会立即把半句话发出。
- 通话期间不插播后台任务通知，工作统筹列表继续更新。Qwen 通话音频使用正常语速，普通朗读的保存语速不变。
- 「静音」释放麦克风，仍可听到回复；「取消静音」重新获取麦克风。
- 「挂断」停止本地识别、待播声音和等待中的浏览器请求。已交办的后台任务不会因此撤销。
- 离开助理会话、切到后台、锁屏或关闭页面结束本次通话。恢复页面后需要重新主动发起，不自动打开麦克风。
- 连接超过 20 秒仍未进入聆听时结束，并提示检查麦克风权限。权限被拒绝或浏览器不支持时允许重新尝试。
- 通话中显式播放助理回复；保存的默认播报偏好不变。下载 MP3/WAV 仍由 TTS Tools 提供。

浏览器需要支持 SpeechRecognition 或 webkitSpeechRecognition；麦克风权限和语音识别服务由浏览器管理。推荐在 HTTPS 或 localhost 使用。没有可用助理模型时，语音入口不代表模型服务可用，模型错误仍沿既有链路显示。

## 验证边界

生命周期测试覆盖静音/恢复、挂断、迟到授权释放、权限拒绝、不支持浏览器、连接超时、锁屏及中断。真实麦克风识别质量、扬声器回声和真实云端模型/TTS 的听感需要设备验收；模拟测试不代表这些项目已通过。具体执行结果见 [任务记录](tasks/assistant-voice-call-20261023.json)。
