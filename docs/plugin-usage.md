# 插件从哪里开始用

在右侧打开 **插件 → 已安装**，找到插件后点 **怎么使用**。每个安装包都有这个入口；插件停用或载入失败时也能查看说明。

- 有独立工作台：点 **打开工作台**，按页面提示选择文件、连接或示例。工作台顶部也有 **怎么使用**，关闭说明会回到原工作台。
- 视频和 STEP 预览：先点 **从项目文件打开 → 前往项目文件**，选择视频、剪辑工程或 `.step` / `.stp` 文件，再选择插件打开方式。空工作台没有可读取的文件。
- 对话工具：在对话中说明输入、目标、保存位置和验收要求，让模型调用工具。工具开关、文件权限和审批照常生效。
- 模型价格、账户或路由适配：在模型设置中配置提供商和可用模型，再使用对应策略；安装插件不会提供模型账户。
- 只有能力声明的包：说明会明确提示当前没有独立工作台或可执行工具，不把安装或启用当作能力已经运行。

**已启用**只表示允许载入。是否配置完成、连接成功、文件真正保存，仍需根据实际结果核对。**启用插件 / 停用插件**按钮表示即将进行的操作。

需要配置时，可在说明中点 **插件设置**。更多安装步骤在 **查看安装包内说明** 中；这里展示包内 README 的文字，不执行其中的脚本，也不改变安装包。未附说明或说明被截断会明确提示。

如果载入失败，先看插件卡片的错误和说明中的依赖要求；核对设置后刷新。需要独立引擎、原生宿主、账号或设备的插件，必须先具备其对应条件。公共说明入口不会安装依赖或绕过授权。

目标验收和项目知识表单的未提交草稿在当前页面内按项目保存，切换任务/历史后仍保留；刷新整个浏览器前请保存。原记录发生变化时，先核对当前记录，再明确选择继续使用草稿或放弃草稿。项目知识的主题、内容和来源与版本均必填。

接口：`GET /api/plugins/{id}/guide` 返回当前安装身份、能力类型、工具是否可执行及最多 128 KiB 的包内 README；不返回设置、密钥、工具参数 schema 或价格目录。需要现有鉴权，锁屏时返回 423。README 仅从插件目录内固定文件名读取，不能通过路径参数读取其他文件。

本页描述源码行为。程序版本、已安装插件版本和原生/账号/设备验收分别核对；源码合并不会替换正在运行的服务。
