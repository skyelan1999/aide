# 0.1.19.0 RC2 使用与迁移说明

RC1 仅保留失败候选的源码标签，没有公开程序 Release。RC2 补齐 Docker 测试阶段的冻结市场清单输入后重新验收；市场所标最低宿主 RC1 可由 RC2 或更新版本满足。

[v0.1.19.0-RC2 预发布](https://github.com/skyelan1999/aide/releases/tag/v0.1.19.0-RC2)已于 2026-11-12 公开，发行源码为 `a9f8f412`。实际平台、SHA-256 和完整验收报告见 Release 的七个附件，以及[发布回执](reviews/2026-11-12-release-preparation/publication-rc2.json)。[English](en/release-guide-0.1.19.md)。

## 更新顺序

1. 备份配置和数据，保留旧完整发行包及镜像。确认实际 Docker 引擎是 arm64 还是 amd64。
2. 发行安装使用同架构完整包走既有 A/B 健康检查；源码安装更新源码后显式 build。日常 start 不编译，刷新页面不会更新二进制。
3. 配套更新原生启动器及助手。仅更换容器或仅保留旧助手不能获得新的自选目录对象固定保证。
4. 主程序更新后，再从市场更新 SQLite 1.0.3 与 StarLink 0.1.6。市场标注最低 Aide `0.1.19.0 RC1`，不向旧运行包承诺新宿主能力。其他插件按自己的市场身份升级，不被主程序替换。

## 工作区、引用与文件工作台

文件工作台可在当前工作区和已启用引用之间浏览、打开和保存声明支持的格式。保存到引用仍需 RW，AI 访问还受该工作区的可见性控制。冲突检查失败时保留草稿，重新读取确认；不能把“已生成”当成“已保存”。Professional Resume 0.1.1 等插件的工作台使用宿主受控文件通道，不拿到通用磁盘权限；密码和文件内容是否交给模型按实际操作决定。

自选本地目录继续显示为 `/mounts/<id>`。原生助手持有实际目录对象，通过 loopback NFSv3 和 Docker 命名卷服务文件；准备后替换目录/父目录时，运行容器仍访问原对象。后续准备发现同名对象身份变化会拒绝，须明确移除后重新选择。配置、只读和磁盘权限继续生效，不扩大全局既有挂载边界。

桥接 RO 在服务端执行；文件同步后确认写入。宿主休眠、助手退出或磁盘故障可能产生 I/O 错误，须读取确认结果。`nolock` 不协调宿主其他数据库写入，必须停止并发写；特殊文件和其他用户所有权变更不支持。macOS 临时目录实际 Aide API 验收、Windows 构建及隔离 UI 验收不等于 Windows 目录桥接、TCC、网络盘或热拔插实机验收。

Windows 活动目录句柄可能使系统拒绝该目录或父目录的重命名。需要改名或移动时，先移除相应选择并正常应用或停止，确认对应桥接退出，再操作宿主路径。不要强制删除目录或用户数据来处理“正在使用”提示。

## SSH 与插件

工作区 SSH、独立 SFTP 引用、插件自己连接的设备 SSH 是不同身份。禁用、隐藏、只读或连接代次变化不能通过旧缓存继续访问。

- SQLite：本地相对路径跟随当前工作区；远端使用单调用临时 checkout 和宿主受控写回。每文件及每调用合计 64 MiB、最多四槽；非空 WAL/journal 拒绝。先停止外部写入并 checkpoint，直到操作结束保持停写。它不是远程数据库锁或分布式 CAS，也不提供数据库和导出文件跨槽原子事务。导出可指定独立 RW 来源。
- StarLink：读取当前工作区匹配的 AI scope 星图，支持 SSH 身份；全 Unicode case folding 与规范化改进检索，摘录保留原文。隐藏引用或权限/锁定代次变化会失效缓存。索引未覆盖不等于内容不存在，静态关系不证明执行。
- Office 与附件：DOCX 结构、评论、resolve 以及文档/图片附件绑定选定工作区或引用；读写权限与来源身份在暂存和保存期间重查，不回退本机同名文件。
- Terminal：市场当前包按自己的版本发行。设备连接仍需单独凭据；本次夹具不能证明客户 SSH、串口或 X Server 已验收。

## 大文档、PDF 与预览

上下文压缩按当前请求的实际剩余窗口保留历史，避免仍沿用固定保留预算而拒绝可容纳的请求；当前输入本身超限仍会拒绝。需求及阶段文档索引保留完整的中英文标题。Windows 中文源码路径可验证并复用所属构建缓存，错误或多余的凭证内容仍会拒绝。

超过内联预算的 Markdown 通过路径、摘要及有限节选进入任务，按需分段读取；模型窗口预算仍生效。仅附件可发起任务，长粘贴可转成 Markdown 附件。附件是任务资料，不等于无界上下文或全部正文已送出。

Markdown PDF 导出保留可检索文字、分页表格和独立图像，嵌入附件可在标准附件面板找到。实际浏览器验收包括九页中英混排、100 行表格、PNG/SVG 和两个各 50 MiB 附件；100 MiB 是附件合计，不是 100 MiB 可见正文。PDF 兼容和内存上限不能从该夹具无限外推。

JPEG2000 预览使用固定源码、补丁与编译器生成的 OpenJPEG fallback，替换不可核验的压缩代码修改。构建可复现、原生 sanitizer 和分配故障测试已记录；与独立构建 CLI 一致不是独立标准认证。无法再次复现的历史浏览器下载退出 #776 仅暂时关闭，原始原因未知。
