# 按需执行环境需求（2026-11-01）

用户确认：X 表示资源容量，10X 包含一个主环境和最多九个临时环境；调度自行分工，不固定角色，不强制占满。保留已有上下文恢复、读取优化、版本化提案能力，不影响其他项目的正常开发。

验收：

- 1X 与多 X 复用主工具循环。主模型按需提交、等待、取消任务，依赖失败不执行下游，不按清单强制扇出。
- 每个临时环境有私有源码快照、工具状态、插件副本及守护实例；不切换全局工作区，不复制真实会话、引用配置或磁盘凭据。
- Shell 和私有插件进程使用 Linux Landlock；不可用时拒绝执行，不降级为无隔离进程。主项目原有能力不受限制。
- 任务交换区带版本、来源及未验证标记；并发更新比较版本。调度根据结果进一步分工。
- 浏览器、电脑及设备通过主协调器的原工具、审批和资源队列执行，不复制设备会话。
- 合并先检查工作区身份、所有候选路径与完整内容哈希、已有提案冲突，然后走普通 write_file 策略、钩子、审计、检查点及审批；不得直接应用主项目文件。
- 成功、失败、取消均回收临时环境，保留候选与工具证据。暂停后保留已结束结果，恢复不得自动重复副作用。
- Luna 实测同时记录实际环境数、插件调用、待审批状态、最终应用后断言、耗时和 Token。耗时不等同于倍率承诺。

范围：聊天任务调度及其运行时；不发布、不部署、不切换当前生产服务、不提交或推送。
