# UI 克制化与长时间工作体验记录

日期：2026-10-02
范围：工作台默认首页、常用状态文字、模型设置对话框，以及明/暗主题基础色。

## 设计意图

让界面把注意力留给用户正在做的事。使用低饱和中性色承载大面积背景，以单一品牌色表达主要操作和键盘焦点；减少装饰性动效与玻璃/阴影的视觉重量。辅助文字仍保留层级，但避免落到难以阅读的微小字号。首页文案维持协作语气，不把用户熟练度做成排名、评分或成就反馈。

## 改动

- 调整明暗主题的中性色、边框和状态色：页面背景更柔和，品牌蓝与成功/警告/错误色更克制，语义令牌名称未变。
- 收敛玻璃效果：降低饱和度和模糊半径，提高面板不透明度；减少输入区浮层阴影，并响应 `prefers-reduced-transparency`。
- 移除品牌图标旋转缩放和首页卡片上浮；保留轻量背景/边框变化、键盘焦点轮廓及 `prefers-reduced-motion` 现有支持。
- 桌面首页改为三列入口卡片；为常用状态和设置说明设定更易读的字号与行高。
- 更新 `macos.css` 的缓存版本，确保页面加载新样式。

## 验收记录

- 从仓库源码构建独立 Docker 预览镜像成功；构建阶段的 JavaScript 语法检查、`go vet` 和 Go 编译成功。未运行全量测试。
- 在独立隔离实例的浏览器中，按 1280×720 视口目视检查深色主题：首页五个入口完整可见，品牌/卡片无弹跳式动效；模型设置对话框的标签、说明、输入控件保持清晰层级。
- 预览使用临时数据目录和单独端口，没有连接、重建或写入现有 9999 实例。

## 未覆盖

- 本轮没有实测浅色主题、绿色/舒适主题、移动窄屏、虚拟形象、长会话滚动和真实模型请求；相应结论不从源码调整推断为视觉验收通过。
- 浏览器预览使用本机隔离实例；macOS 系统浏览器当时处于锁屏状态，故未在 Safari 中操作。
