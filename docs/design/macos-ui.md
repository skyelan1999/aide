# aide · macOS 界面优化

日期：2026-09-23。分支：`feat/macos-ui`。此次由 Codex 直接设计、修改和浏览器目视检查，DSH 的 UI 任务已停止。

## 设计与实现

- 以系统字体、中性灰白／深灰表面、蓝色强调和统一线性 SVG 图标建立一致层级，沿用现有主题设置与语义颜色变量，无新运行依赖、远程字体或 CDN。
- 重新安排侧栏、欢迎页、输入框、文件列表；居中的设置窗口采用导航与内容双栏，窄屏改为横向导航。
- 费用展示分为累计用量、已计价费用、刊例价估算；保持原有服务端计价口径。热力图增加键盘方向键导航、单日明细自动滚入可见区域。
- 文件预览、独立文件页面、轨迹窗口、Markdown 表格与代码块使用一致的阅读尺度。修复回复继承 `pre-wrap` 导致表格布局异常的问题。
- 窄屏可通过顶部按钮打开会话抽屉；文件／插件面板有关闭入口，切换按钮的选中状态与面板保持一致。设置与导航抽屉支持键盘焦点循环。
- 保持随系统外观、中文输入法保护；新增减少动态效果、增强对比度和安全区域样式。

主要文件：`internal/server/web/macos.css` 为表现层；两套 `themes/*/tokens.css` 为颜色值；`index.html` 为结构与图标；`app.js` 仅涉及界面展示、导航与键盘操作。未修改 Go 后端或数据格式。
