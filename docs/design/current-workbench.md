# 当前工作台交互设计

2026-10-17，源码 `0fef6411`。本页描述已经可见的交互布局，配图全部来自[实际运行截图](../ui-evidence.md)。历史 macOS 概念稿和日期设计继续保留，仅用于追溯。

## 信息层级

![当前三栏工作台](../images/current-20261017/01-workbench.jpg)

左栏管理工作空间、助理、会话和累计用量；中央承载工作成果、任务过程和输入；右栏切换消息、插件、项目文件。侧栏可调整宽度。主视区保持真实文档和成果优先，工具明细按需展开。

任务状态、待审批与停止操作放在输入框附近，减少上下翻找；不能同时把过期任务的“继续”表现成当前运行主操作。并行明细默认收敛，累计用量与单次窗口分开，长请求不能把左侧无限撑高。压缩状态使用独立进度/动效；此次无模型请求，截图未覆盖压缩或运行状态，不将设计要求记成验收通过。

## 控件与边界

![实际主设置](../images/current-20261017/05-management.jpg)

设置采用侧导航、内容区和独立滚动；管理权限按“角色 × 管理对象”排列。文本、标签、输入和按钮保留内边距；长描述自然换行。1280×720 截图实际存在导航换行和需滚动的长表单，不据此宣称所有分辨率布局已完美验收。

引用条目把来源选择、AI 可见和可写三个含义分开，不用一个开关同时代表全部授权。自动系统文档固定条目展示实际绑定；目录配置、读写授权和一次提案确认是不同操作。

## 助理与消息

![工作统筹设置](../images/current-20261017/06-assistant-settings.jpg)

助理以工作统筹为主，通过身份验证后自动跟进。语音回复偏好集中在设置；页面不重复放陪伴总开关和语音回复条。麦克风只在用户主动开始后工作；说话打断需实际麦克风验收。设置模型来源应复用已配置模型选择，不能仅把提供商来源当模型本身。

![原有提醒归入消息](../images/current-20261017/10-reminders.jpg)

消息中心的四个标签稳定占位，提醒筛选与消息标签使用不同层级。账户名是通信显示名，缺失时显示原因与前往账户设置入口；联系人、群组、通话、文件邀请分别明确同意动作。消息设置进入主设置，不在小面板重复维护设备名。

## 视觉验收方法

当前截图使用专业深色、背景关闭和示例数据。每次交互变更需在实际浏览器检查普通正文、长表格/代码、长控件说明、侧栏收窄和滚动；浅色、系统跟随、背景素材及其他平台需另取实际截图。保持原图并记录源码与环境，不用修改截图遮盖真实布局问题。本次只更新文档，没有调整产品 CSS 或重启用户服务。

## 内置鲸鱼娘背景

设置 → 外观 → 工作台背景 → 鲸鱼娘，可直接选择随应用内置的静音循环视频，无需上传。默认仍关闭，原有强度调节、本地素材与后台/锁屏/减少动态效果暂停规则保留。[实际截图与实现边界](../builtin-background.md)。
