# 助理朗读与通话

在「设置 → 助理与语音 → 语音助理」选择一个模型提供商。朗读与通话复用该连接在「模型设置」中的活动密钥。打开页面、切换提供商或保存模型设置时自动检索。朗读也可以选择当前可用的本地离线、浏览器合成和 edge-tts。兼容 OpenAI Speech 的本机连接允许使用免密钥目录和合成接口。

语音列表根据提供商返回的模型目录和 Aide 支持的语音接口生成。模型设置里已保存的同连接模型可提供显示名称和语音接口类型。未出现在目录的云端模型不显示。通话列表只显示可接入原生双向语音的模型。目录查询确认连接和模型列表，试听或拨通时才检查实际合成或通话权限与额度。

## MiMo 朗读

选择已配置的 MiMo 或 MiMo Token Plan 提供商，再选模型与音色，点击「试听」即可测试。支持按量付费地址和中国、新加坡、欧洲 Token Plan 集群。服务端从加密 vault 读取所选连接的活动密钥，朗读设置不改变它。

支持标准预置音色 `mimo-v2.5-tts`，以及文本音色设计 `mimo-v2.5-tts-voicedesign`。角色描述会作为合成指令传入；标准模型将其作为可选语气提示，音色设计模型要求填写。TTS 模型目录不展示 `mimo-v2.5-tts-voiceclone`：该模型要求上传音频样本，本设置尚未提供样本上传与同意流程。

目录发现使用 MiMo `GET /v1/models`，合成使用 `POST /v1/chat/completions`，音频通过 WAV 返回并由现有助理朗读播放器播放。上游额度和费用遵循 MiMo 账户策略；刷新目录只读取模型列表，试听会实际请求音频合成。

参考：[MiMo 模型列表 API](https://mimo.mi.com/docs/zh-CN/api/model/list-models-get)、[MiMo TTS API](https://mimo.mi.com/docs/zh-CN/api/audio/tts-post)、[模型能力表](https://mimo.mi.com/docs/zh-CN/quick-start/summary/model)。

## 原生通话中的会话与审批

OpenAI 实时通话接通时，小绵会用一句引导话接续近期话题。你可以查询当前工作区、会话运行、已安装插件或待人工审批。需要操作任务时，明确说出动作和会话编号，例如「暂停会话 #12」。助理会按会话的当前运行状态提交请求，执行结果显示在对应会话里。

需要人工决定的操作会显示在助理页面。点击会话编号可打开审批；OpenAI 实时通话也会在对话间隙提醒。对于支持语音确认的单项审批，可说「查看会话 #12 的审批」，在通话面板核对完整命令或文件改动后，再说「批准本次审批」或「拒绝本次审批」。同一会话有多项待审，或事项需要在原会话确认时，请打开对应会话处理。

助理创建会话后，侧栏会自动刷新，当前输入的草稿会保留。
