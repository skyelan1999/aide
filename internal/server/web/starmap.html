索引范围与证据

恒星包层大小、星色与光晕由有效关联数驱动：关联越多，文明可调度的能量预算越高，恒星工程包层越醒目。0 灰星；1–2 暖红；3–7 金色；8–15 白色；16–31 蓝白；32+ 蓝色强光。关联数为去重邻居，排除目录包含与声明关系；跨文件调用同时计入所属文件。高亮星为全图关联数最高约3%的真实节点（至少8条）。黑洞仅表示分组内节点规模和有效关联密度都较高的区域，最多显示3处；面积为相对图谱指标，不代表实际天体质量。颜色和图形均是可视化隐喻，不是物理测量。

星域画面使用统一的光学近似：恒星的索引连接数映射为叙事用发光功率，投影深度进入平方反比视亮度；跃迁门由两端系统资源共同限制稳定度与通行量。黑洞附近再使用无量纲点质量薄透镜方程叠加背景星与索引光路的偏折像。场景深度不是天文距离，连接数不是恒星质量，所有参数用于一致的交互式视觉模拟而非观测预测。

黑洞外观借用近乎侧视的吸积盘观测线索：中央暗影遮住背景，紧邻暗影的细光环表示光子环；被引力透镜弯折的盘面可在暗影上下形成弧状像，盘的一侧会因相对论性多普勒增亮而更亮、更偏蓝，远离的一侧更暗、更偏红。NASA 的说明指出，黑洞本身不发光，暗影视直径约为事件视界直径的两倍，盘和透镜后的光才构成可见结构。星图用点质量薄透镜方程计算局部光线的主像、次像与连线偏折，并以独立 Canvas 光学层叠加；图谱密度只提供无量纲的视觉尺度，不提供真实质量或源距，因此这不是对真实黑洞的物理参数拟合，也不是时空测地线积分或完整相对论光线追踪。这里的“黑洞”仍是关联密集区域的图谱标记，尺寸不代表黑洞质量、视界尺度或真实观测图像。

黑洞外观依据：NASA：黑洞结构、吸积盘、引力透镜与多普勒增亮 · EHT：黑洞暗影与光子环。

跃迁纪元 · 星图编年

很久以前，恒星彼此孤立，文明只能沿着缓慢而脆弱的航线迁徙。掌握恒星磁场编织与星体物质转移后，人们建起环绕恒星的能量采集群，并以受控星风、磁通管和轨道上的跃迁门，把星际航道接入各个知识星域。每一条被索引证据连通的星际关系，都是星图中一条可追溯航路；有效邻居越多，调度网络越繁忙，恒星周围可用的工程功率与包层设施也越庞大。图上的半径因此是对数压缩后的“文明能量包层”规模，绝非恒星真实半径或光度读数。

星门不是凭空出现的虫洞：它们是架设在恒星引力井外缘、成对校准的跃迁设施，锚定真实跨恒星系统的索引连线。图中的门方位取自该系统与目标系统之间已索引边在星图布局中的合成方向；门面横向于航路，多个目的地按方向分布，近似重合时再以不同轨道半径避让。这个方位是知识图谱的导航方位，不是天文学坐标或现实宇宙测量。靠近恒星系统时可看见不同目的地的门；点击即可沿对应索引关系跃迁。造型采用大型工业骨架、分段装甲与受控等离子光核的科幻语言，不复用 EVE 素材。

恒星系统里的“行星”承载知识生态：文档是保存完整脉络的档案世界，代码声明是彼此协作的工坊群，会话则是记录探索过程的短周期港站。每颗行星都对应真实索引节点，保留原编号、来源与关系；没有真实节点，就不生成虚构行星。恒星系统来自同一文件／声明范围内已解析的局部调用分量；这些静态调用候选并非运行时航迹。

物理边界：恒星总辐射功率满足 L = 4πR²σT⁴。在表面温度不变时，若真实半径增大，恒星光度也会按半径平方上升，并影响周围行星收到的辐照；不能把“关系更多”直接当成真实恒星变大。星图把连接数映射为文明采集、储能和跃迁设施形成的工程包层。理论研究曾模拟通过恒星采集／移除物质来调节辐照并延长主序寿命，但这仍是理论模型，不是已实现技术。

物理依据：NASA：恒星光度与斯特藩–玻尔兹曼关系 · MNRAS：恒星物质采集与寿命延长的数值研究。造型参考：EVE 宇宙：星门技术（成对节点、校准与中心光核）。
