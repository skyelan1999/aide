A FEW THINGS TO KNOW

开始之前，
你可能想知道。

这个网站能直接运行 aide 吗？＋

这是 aide 的产品主页。aide 本体需要在你的电脑上安装运行，再通过浏览器进入本地工作台；它面向可信单用户使用，不提供公网多用户托管。

aide 是免费的吗？＋

aide 源码采用 MIT License。模型服务由你自行配置，云端模型可能按提供商规则收费；本地模型也需要相应的运行环境。

可以使用自己的模型吗？＋

可以配置兼容 Chat Completions 的模型服务，包括可访问的本地服务。具体兼容性取决于服务的 API 与工具调用支持，保存配置后请先用一个简短问题检查连接。

本地运行时，资料会发送到哪里？＋

项目与会话数据在本机持久化。使用云端模型时，任务内容、上下文和工具读取结果会发送给所配置的提供商；请根据资料要求选择模型服务与可访问的工作目录。
